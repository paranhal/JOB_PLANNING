# 화면 개선 배치 (D-176, 95-31)

`.cursor/rules/screen-replace.mdc` 와 같다. 저장소에서 `.cursor/` 가 무시되므로 여기에도 둔다.

기존 화면을 개선한 새 화면을 만들 때:

1. 새 화면을 **기존 메뉴 위치**에 둔다.
2. 기존 화면은 삭제하지 않고 사이드바 **「예전 화면 보기」** 아래로 옮기고 이름에 `(예전)` 을 붙인다.
3. 새 화면 안에 **「예전 화면으로」** 링크를 작게 둔다(기능 누락 시 되돌아갈 길).

제자리 수정(같은 주소)은 예전 화면을 따로 남기지 않는다. 95-23 「기존 기능 연동 점검표」와 함께 본다.
