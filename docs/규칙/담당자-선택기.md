# 담당자 선택기 (95-51 / 95-25)

담당자 **지정 입력**은 `assignee_picker` 템플릿과 `ParseSelection` / `SaveAssignees` 만 쓴다.

- 템플릿: `web/templates/_ui_assignee_picker.html` (`{{template "assignee_picker" …}}`)
- JS: `web/static/js/assignee_picker.js` (`assigneePicker`. 한 단계 `mntAssigneeMulti` 별칭)
- 서버: `handler.ParseSelection`, `repository.SaveAssignees`
- 목록 공급: `listAssignableForPicker` / `assigneeFilterOptions` (조직 격리)
- 조회 SQL: `repository.SQLAssignedToUser` (`assigneeMatchSQL` 위임)

목록 **필터**용 `<select name="assignee">` 는 UI를 유지하되 옵션은 `assigneeFilterOptions` 로 공급한다.
구 폼 값(`assignee`, `assigned_to_code`)은 한 단계 호환한다.

95-26 타팀 지원(`AllowCrossOrg`)은 이 단계 false.
통계 담당자별 건수는 주담당 1명 기준.
