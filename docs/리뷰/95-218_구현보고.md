## 아직 안 한 것 / 알아 둘 점
- **「사업 사이트에 추가」 이동 버튼은 만들지 않았다.** 거절 문구에 이유와 방법만 안내한다(사업 상세 사이트 등록으로 가는 버튼은 별도 작업).
- AS 사업 연결은 제품 정보를 넘기지 않아 범위 규칙 중 **제품 키가 없는 규칙**만 (나)로 인정된다. 사업 사이트(가) 기준은 방문과 같다.
- 일반 업무 연결에는 원래 사이트 검사가 없어 이번에 손대지 않았다(방문·AS가 일반 업무보다 느슨해졌을 뿐 더 엄격하지는 않다).
- 기존 방문 데이터 백필은 하지 않았다(후보 1개로 확정되는 건의 목록 화면도 이번에는 만들지 않았다 — 별도 승인 후 별도 지시서).
- 완료 화면에서 브라우저 콘솔에 `Unexpected token 'var'` 오류가 보인다. 이번 변경과 무관한 기존 Alpine 속성 문제로 보이며(이번 변경은 Alpine 코드를 건드리지 않음) 이번에 고치지 않았다.
