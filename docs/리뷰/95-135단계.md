## §3-1 `activity_kind` 처리 위치와 새 유형 영향

컬럼은 `weekly_report_rows.activity_kind` (078, TEXT, 기본 `''`). 스키마 변경 없이 값만 추가하면 된다.

| 위치 | 지금 |
|------|------|
| 행 관리 UI | `stats/company_weekly_rows.html` 셀렉트: 빈값·`asset`·`tech`·`mnt_as` |
| POST | `parseWeeklyRowForm` → `InsertWeeklyReportRow` / `UpdateWeeklyReportRow` |
| 정규화 | `normalizeActivityKind`: 활동 행이 아니면 `''`, 허용은 `asset`/`tech`/`mnt_as`만. **`unlinked`는 빈값으로 떨어진다.** |
| 목록 | `ListWeeklyReportRowsOrg`가 컬럼을 그대로 읽음 |
| 초안 | `BuildCompanyWeeklyDraftOrg` → 활동이면 `composeActivityTexts` |
| 집계 | `activityKindOf` / `composeActivityTexts` switch: `asset`/`tech`/`mnt_as`, default는 빈 줄 |
| 화면 카드 | `company_weekly_view.go`: `Kind=activity`면 `activityBadge(ActivityKind, DisplayName)` (`tech`→영업, 나머지 지원) |
| 엑셀 | `company_weekly_excel.go`는 `PrevText`/`PlanText`만 씀. 유형 분기 없음. 초안 텍스트가 채워지면 엑셀은 따라감 |
| 시트 | `company_weekly_sheet.go` 동일 |

**추가 시:** `normalizeActivityKind`·`activityKindOf`·`composeActivityTexts`에 `unlinked` 한 갈래. 행 관리 옵션 「사업 미연결 업무(통칭)」. `activityBadge`에 라벨(제안: 표시명 그대로이므로 「지원」이어도 됨 — 확인).

저장 문서 `ApplyCompanyWeeklySaved`는 `AutoDone`/`AutoPlan` 키로 병합. 통칭도 같은 키 규칙을 쓰면 수동 확정이 유지된다.

## §3-2 Unassigned → 통칭 행

`listCompanyUnassigned`가 이미 모은다.

- **전주 완료 (`bucket=prev`)**: 점검 방문 완료, AS `complete_datetime`, `work_tasks` 완료(`admin`/`support`/`project_work`/`work`).
- **차주 구간 (`bucket=plan`, 화면 라벨 「금주 계획」)**: 선택 주+7일(회의주)의 미완료 행정·작업·점검 예정.
- **이월 (`bucket=carry`)**: 미완료이고 예정일이 비었거나 회의주 시작 전. 점검 미완료도 「미완료」.

사업 행은 `listCompanyAdminCarry`를 **계획 열**에 `(이월)`·`(N주 지연)`으로 넣는다. 통칭도 AutoPlan에 같은 규칙을 쓰는 것이 맞다.

**종류 표시:** Unassigned `KindLabel`은 행정/지원·작업·AS·정기점검. 줄 형식 제안: `[행정/지원] 제목` + 완료일은 사업 행처럼 `(M/D)` 선택.

**묶음:** `collapseCompanyAdminLines`는 **반복 회차(parent_id)만** `제목 N회`로 합친다. 같은 제목의 서로 다른 건은 합치지 않는다. 지시서 「경영지원 업무 ×8」은 제목 단위 추가 묶음이 필요하다(확인).

**중복 방지**

| 축 | 방법 |
|----|------|
| 사업 연결 건 | Unassigned는 `mapped[project_id]`면 제외. `Reason=NoProject`만 통칭에 넣으면 사업 행과 건 단위 중복 없음 |
| 경고 상자 | `dropUnassignedKindsForActivity`(mnt_as 행이 있을 때 AS·점검 미매핑 제외)와 같은 패턴으로, 통칭 행이 있는 조직은 `Reason=NoProject`를 경고에서 제거. MatchPending·NoRow·Foreign 유지 |
| 조직 | `filterAdmin`/`filterAS` org + 통칭 행 `org_id`. Foreign은 통칭에 넣지 않음 |
| 취소 | 완료 쿼리 `status=complete`, 계획 `NOT IN (complete,cancelled)` |

**영업 공백:** `companyWeeklyAdminTypesSQL`에 `sales`가 없고 `ExcludeSalesActivity`로 `source_type=sales_activity`도 뺀다. **지금 경고 8건(행정/지원)에는 영업이 없다.** 지시서 「모든 종류」를 지키려면 Unassigned에 `work_type=sales`·사업 없음 조회를 더해야 한다.

기술영업 활동 행(`tech`)은 다른 집계(`listTechSalesActivityLines`)다. 통칭과 겹치지 않게 사업 있는 영업은 계속 사업/`tech` 행만.

## §3-3 캡처 8건 vs 일일 완료 (운영 DB 미접근)

캡처 문구 = `UnassignedMainN` 요약 + `UnassignedNoProject` 「사업이 연결되지 않은 업무 8건 · 행정/지원 · 전주 완료」.

11/2 주 선택 → `companyWeeklyAnchor` = 11/9(월). 실적 `PrevFrom=11/2` ~ `PrevToEx=11/9`. 기간 계산은 지시서와 같다. 본문 0은 행이 사업 연결 건만 집계해서다.

일일 업무 주간 완료와 어긋날 수 있는 산식:

| | 통칭/Unassigned 전주 완료 | 일일 주간 완료 |
|--|--|--|
| 유형 | admin/support/project_work/work (+AS·점검은 원본 테이블) | 보드에 올라온 모든 일일업무 |
| 영업 | **제외** | 포함될 수 있음 |
| 취소 | 제외 | 완료만 보면 제외 |
| 반복 | `SQLRecurrenceWorkUnit`(회차 단위) | 목록은 건 단위 |
| 사업 있음 | Unassigned에서 빠짐(본문 사업 행) | 주간 완료에 포함 |
| 날짜 | `adminTaskCompleteDateSQL`의 date() | 보드 complete_date/예정일 |

캡처가 「행정/지원 8건」이면 Unassigned 산식과 맞고, 일일 9건이면 **사업 연결 1건** 또는 **영업·반복 회차** 차이일 가능성이 크다. 운영 숫자 확인은 승인 후 화면에서.

## §3-4 조직당 1개

지금 `weekly_report_rows`에 `(org_id, activity_kind)` UNIQUE 없다. `InsertWeeklyReportRow`도 중복을 막지 않는다.

**넣을 곳:** `InsertWeeklyReportRow`(및 활성 행 기준 Update가 `unlinked`로 바꿀 때). 같은 조직에 활성 `activity_kind=unlinked`가 있으면 「사업 미연결 통칭 행은 조직당 하나만 둘 수 있습니다」. 숨김 행은 재활성 시에도 막는다(확인).

행 관리: 활동 종류 옵션 추가. 표시명은 필수 자유 입력. placeholder 제안 「사업 미연결 업무」(경영지원은 관리자가 「경영지원업무」로 입력). 코드로 조직별 이름을 심지 않음.
