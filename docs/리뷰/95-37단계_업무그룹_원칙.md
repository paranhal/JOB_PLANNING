## 구현 요지

- `as_receipts.work_group_id` 마이그레이션 086(멱등) + `ix_wgm_user_group_dates`.
- `mineOrGroupCond`: 사람 매칭 **또는** `EXISTS work_group_members` (업무 날짜 기간). 행마다 `memberOn` 호출 없음.
- `CanManageGroup` = 조직관리자·비전관리자 **또는** 해당 그룹 현재 그룹장.
- `canActForGroupWork` = `canActForOthers` 또는 그 그룹 그룹장.
- 그룹 담당 AS 조치 시 수행자(`worker`) 필수. 알림 `RecordGroup` → 현재 구성원 전원.
- 토글 기본값 그룹 포함. `?scope=` 가 쿠키보다 우선. 쿠키 1년.
- 개인만: `work_group_id` 있는 건 제외. 직접 담당+구성원 중복은 SQL DISTINCT/목록 1행.
