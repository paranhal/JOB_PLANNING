## 폼 오류 → 팝업 + 복귀

- HTML 폼 POST/PUT/PATCH/DELETE 의 400·403·404·409·422 → 일회용 쿠키 `jp_flash_err`(HttpOnly, SameSite=Lax, 최대 300자) + **303**. 복귀 URL: `back`/`redirect`(동일 출처) → Referer → 모듈 목록.
- 500 HTML: 팝업 「처리 중 오류가 발생했습니다」, 상세는 서버 로그.
- JSON/`Accept: application/json`/`X-Requested-With: fetch|XMLHttpRequest`/`HX-Request`/`/api` 는 기존 JSON.
- 레이아웃 모달: 제목 「확인해 주세요」, `role="alertdialog"`, 확인·Esc·배경 클릭.
- 일일업무 모달 4종(`js-keep-modal`): `fetch` + JSON. 4xx면 모달·입력 유지 + 같은 팝업. 성공 시 `redirect`로 이동. JS 실패 시 일반 POST 폴백.
