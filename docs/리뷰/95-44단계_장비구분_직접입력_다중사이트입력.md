# 95-44단계 — AS 조치 장비 구분 직접 입력, 여러 사이트 한 번에 입력

기준: `커서_작업지시서_95-44_AS조치_장비구분_직접입력_여러사이트_한번에입력.md`  
선행: 95-43. 실행일: 2026-10-25.

## 한 줄

AS 조치 1차에 「직접 입력」(`cause_cat1=custom`, `cause_cat1_custom`)을 넣고, 작업 화면 사이트 칩을 `site_multi_picker`로 빼서 AS 접수·AS 조치·행정/지원에 같은 묶음 입력을 준다.

## 라벨 전수 점검

| 화면 | 표시 | 비고 |
|------|------|------|
| AS 조치 (새·조회) | `CauseCat1Label` / `causeCat1Label` | custom이면 입력값 |
| AS 예전 상세 | 1차 분류 행 | 동일 함수 |
| AS 사례 검색 | `CauseName` SQL CASE | custom이면 custom 컬럼 |
| AS 본문 검색 | `CauseName` 뱃지 | 동일 SQL |
| 조치완료보고서 | 1차 분류 | loadAS에서 라벨 |
| AS 현황 | 1차 분류 합산 | `CountCauseCat1` 입력값별 |
| 원인 통계 필터 | 「직접 입력」 옵션 | 지식 검색 `cause_cat=custom` |
| 정기점검 | 변경 없음 | 도서관 전용 유지 |

같은 입력값(대소문자·공백 정규화)은 통계에서 한 줄로 합산한다.

## 공용 컴포넌트 적용 위치

| 위치 | 파일 | 검색 |
|------|------|------|
| 작업 등록 | `workboard/_modals.html` | `/workboard/work-sites/search` |
| 행정/지원 등록 | 같은 모달·`task_show.html` | 동일. 영업은 숨김 |
| AS 접수 신규 | `as/form.html` | `extra_site_id` / 사이트 검색 |
| AS 조치 적용 | `as/action.html` | `/as/open-for-apply` (`extra_as_id`) |

JS: `web/static/js/site_multi_picker.js` (추가·제거·중복·20 제한).

## 묶음 입력

- AS 접수: 사이트마다 접수 1건, 같은 `ReceiptGroupID`. 추가 사이트는 장비 없이. 최대 20곳(21 거부). 토큰은 묶음 1회.
- AS 조치: 선택한 진행 중 접수에 조치 이력 복사. 자재·사진은 원본만. 완료(잠금 해제 전)·타 조직 제외. 담당 tech는 본인 건만 검색.
- 행정/지원: `work_task_sites` 여러 행. 0개면 기존 단일 고객. 목록 한 줄 `외 N곳`.
