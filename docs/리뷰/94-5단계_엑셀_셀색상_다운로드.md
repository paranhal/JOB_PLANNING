# 94-5단계 보고서 — 엑셀 셀 색상 · 다운로드

기준: `커서_작업지시서_94-5_엑셀_셀색상_다운로드.md` · D-108

## 원인

excelize v2.8.1은 색을 6자리 RRGGBB로 받은 뒤 앞에 `FF`를 붙여 `styles.xml`에 8자리로 저장한다. 코드가 `"FF1E3A5F"`처럼 이미 8자리를 넘기면 `rgb="FFFF1E3A5F"`(10자리)가 되고 Excel(Mac)은 그 칸을 검정으로 그린다.

`.crdownload`는 본문·헤더 코드만으로는 재현되지 않았다. `writeDownloadBytes`는 `Content-Length`를 본문 길이와 같게 주고, ASCII `filename` + UTF-8 `filename*` + `.xlsx`를 쓴다. gzip 미들웨어는 없다.

## 동작

- `xlColor`: `#` 제거, 8자리이고 앞이 `FF`이면 앞 두 글자를 제거, 대문자 6자리 RRGGBB.
- 5개 파일의 Font/Fill/Border 색과 전사 주간 탭색을 헬퍼로 통과.
- 다운로드 헤더는 **변경하지 않음**(2-B 원인 미확정).

## `.crdownload` 진단

- 로컬 `:8080`은 이 작업 시점에 리스닝이 없어 `curl` 응답 헤더를 받지 못함.
- 코드상 헤더: `Content-Type` spreadsheetml, `Content-Disposition` `filename="….xlsx"` + `filename*=UTF-8''…`, `Content-Length`=본문, `X-Content-Type-Options: nosniff`, `Cache-Control: no-store`.
- **원인 판정: 미확정. 헤더 수정 안 함.** HTTP·Chrome 「유지」 또는 PC 백신이 후보. HTTPS는 코드로 해결되지 않음.

## 브라우저·Excel 확인

에이전트 환경에 Excel(Mac/Windows)이 없어 헤더/휴일/0건/합계 색 스크린샷은 확인하지 못함.

## 질문

1. 주간 보고·자산 등 **다른 엑셀도** `.crdownload`로 남는지.
2. Chrome / Edge / Safari 각각 결과와 Chrome 다운로드 목록의 경고 문구.
3. 운영 주소 `curl -sD - -o /dev/null` 헤더를 세션 쿠키로 찍어 줄 수 있는지(쿠키 값은 보고서에 적지 않음).
4. Excel에서 색이 보이는지 스크린샷.
