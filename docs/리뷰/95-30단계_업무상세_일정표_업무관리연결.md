## 동작

- 링크 기본값은 `workboardHomeURL(date)` 한 곳(`server/internal/handler/workboard_home.go`). 템플릿 FuncMap과 핸들러가 같이 쓴다. 빈 날짜 → `/workboard/board`, 있으면 `?view=month&date=YYYY-MM-DD`(잘못된 값은 오늘).
- `일정표`는 항상 `workboardCalendarURL(WorkDate, DueDate)` → `/workboard/board?view=month&date=…`. **BackURL을 쓰지 않는다.**
- `back` 쿼리가 없으면 돌아가기 기본값은 `/workboard/board`, 문구 `← 업무 관리`. 명시적 `back`은 그대로. `back`이 `/workboard/register`이면 문구·메뉴 활성(`NavWorkRegister`)만 예전 화면 유지.
- `/workboard/register` 화면과 메뉴 「예전 화면 보기」는 삭제하지 않음. `workboardRedirectPathOK` 허용 목록 변경 없음.
