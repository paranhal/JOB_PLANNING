## 1. 새 표 `as_cause_category_orgs`

기존 `as_cause_categories` 는 수정하지 않았다. 마이그레이션 `102_as_cause_category_orgs.sql`: PK `(org_id, code)`, UNIQUE `(org_id, level, parent_code, label)`.

코드는 `CauseOrgPathCode(org, L1, L2, L3)` — SHA256(`조직·1차>2차>3차`)의 앞 10바이트 hex에 `g` 접두. 같은 파일을 다시 올려도 코드가 같다.

## 2. `ListCauseCategoriesForOrg`

순서: 조직 표 행이 있으면 그것 → 없고 `O01`이면 기존 `as_cause_categories` → 둘 다 아니면 빈 표.

`as.go` Show/Action/Update, `CauseCategoriesJSON`, 통계·라벨(`as_report.go`, `CountCauseCat1`)은 **접수 건 `as.OrgID`** 기준. 로그인 조직이 아니다. 라벨은 `ListCauseCategoriesForOrgAll`(비활성 포함). 지식검색 등 기존 `ListCauseCategories()` 호출은 그대로 두었다.

## 3. `/as/cause-categories`

- 양식 `원인분류_양식.xlsx` (입력 · 작성 안내 · 장애유형 목록)
- 현재 분류표 내려받기
- 미리보기 / 적용 / 오류 목록 엑셀
- 메뉴: 설정·관리 더보기, `isOrgAdmin() && !IsReadOnly` 만. 비전·기술·C-Level은 메뉴 없음, 직접 주소 403(양식 포함).
- 대상 조직은 로그인 조직관리자 본인 소속 하나(조직코드 열 없음).

## 4. 빈 표 · `causeRuleFor`

분류표가 없으면(활성 1차 없음) 조치 화면은 1차 직접 입력 필수(마지막 조치만) + 2·3차 글자칸. 서버는 `causeRuleFor`가 빈 표면 `causeCatFreeInputErr`(`cause_cat1_input`), 표가 있으면 기존 `actionCauseCatMissingErr` 그대로. `actionCauseCatMissingErr` 본문은 수정하지 않았다. 빈 표에서는 `ApplyCauseCat1`를 타지 않는다.
