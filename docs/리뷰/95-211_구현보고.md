# 95-211 구현 보고 — 긴급: 주간 업무 보고서 「팀 전체」 란 항상 표시

작성: 2026-11-15. 지시서 `Claude outputs/코드_작업지시서_95-211_긴급_…md`. **커밋 해시는 §8**. 푸시·배포·VERSION 변경은 하지 않았다.

## 요약 (배포 판단용)
- **표시 버그였다.** 「팀 전체」 박스가 조건부로만 그려졌고(보기: 내용 없으면 통째로 생략 / 편집: 카드 0개 분기에 입력칸 없음), 이를 항상 그리도록 고쳤다. **저장 형식·집계·엑셀·HWPX·저장 데이터는 건드리지 않았다.**
- 게이트: **통과 2668 / 실패 7 (기존 7 · 신규 0)**. `TestWeeklyTeamBoxAlwaysRendered`(32조합) 포함. 실제 브라우저(1440/820/390) 통과.
- **운영 데이터 확인(SQL)은 사용자 지시(「지금 바로 구현해」)로 결과를 받기 전에 구현했다.** 코드에는 팀 전체를 비우는 경로가 없음(§2)을 확인했지만 **운영 데이터 보존 여부는 이 보고서로 판정하지 못했다.** 배포 후에도 SQL(0단계 보고의 ①②)을 실행해 조직별로 `team_done`/`team_plan` 이 남아 있는지 확인해 달라. 값이 있는데 화면에 안 나왔다면 이번 수정으로 보이고, 사라졌다면 `updated_by/updated_at` 조사가 별도로 필요하다.
- **기존 시험 1건의 기대값을 바꿨다**(§5): `TestHTTP95_190_NoLinesNotice` — 카드 0개 편집 화면이 「저장 막대 없이 다시 집계만」이던 것을 규칙 R 에 맞게 「팀 전체 입력칸·저장 막대·다시 집계 함께」로.

## 1. 원인 (`stats/company_weekly.html`)
1. 보기 모드: `{{if or .View.TeamDone .View.TeamPlan}}` — 저장된 팀 전체가 **없으면 박스 자체가 없다**(확정됨·미입력 조직, 읽기 전용).
2. 편집 모드 카드 0개: `{{if eq (len .View.Cards) 0}}` 분기에 안내문과 다시 집계 버튼만 있고 **팀 전체 입력칸·저장 막대가 없다**.
3. 보고서가 아직 없는 주차(「이 주차에 보고 내용이 없습니다」)에도 박스가 없었다 → 자동 생성 직후 카드 0개 편집 화면에서 팀 전체를 적을 방법이 없었다.

## 2. 팀 전체를 비우는 코드 경로 (없음 — 시험으로 고정)
- 비우는 경로는 편집 폼의 `touch_team=1` 로 두 칸을 모두 비워 저장하는 경우뿐(`stats_company_weekly_ui.go:269`). 자동 생성·행 저장(`touch_team` 없음)·다시 집계(`touch_team` 없음)·확정·확정 해제·구형 저장은 기존 문서를 읽어 팀 전체를 그대로 다시 저장한다.
- `TestWeeklyTeamKeptByOtherPaths95_211` 이 생성·행 저장·다시 집계·확정 뒤에도 팀 전체가 유지됨을 단언한다.
- 참고: 보고서 JSON 은 `omitempty` 라 비면 키가 저장되지 않는다 → DB `NULL` 만으로는 「안 적음」과 「빈 칸으로 저장」을 구분할 수 없다(`updated_by/updated_at` 필요).

## 3. 변경 (템플릿 1개)
- **규칙 R**: 「팀 전체」 박스는 보기/편집·확정/작성 중·카드 0개·내용 없음·읽기 전용 모두에서 항상 그린다.
- **보기 모드·읽기 전용**: 공용 정의 `weekly_team_read` 로 항상 박스를 그리고, 비어 있으면 두 칸 모두 회색 「입력된 내용이 없습니다」(`data-weekly-team-empty`). 편집 가능한 사용자에게는 보고서가 있고 비어 있을 때만 「「편집」을 누르면 팀 전체 내용을 입력할 수 있습니다.」 한 줄(`data-weekly-team-hint`). 내용이 있으면 현행과 같은 줄 표시.
- **편집 모드 카드 0개**: 카드 수 분기를 없애고 **같은 폼(`weekly-form`)·같은 팀 전체 입력칸·같은 저장 막대·스크립트**를 쓴다. 「편집할 사업·활동 줄이 없습니다…」 안내는 폼 위에 그대로 두고 「팀 전체 내용은 아래에 적고 저장할 수 있습니다」를 덧붙였다. `touch_team=1` 유지, 다시 집계도 저장 막대에서 가능.
- **보고서가 없는 주차**: 안내 카드 아래에 읽기 박스(비어 있음)를 그린다(작업지시서에 명시되지 않은 경우 — 「어떠한 경우라도」에 맞춰 포함, 원치 않으면 한 줄 제거).
- 마크업·클래스·`data-weekly-team`/`-read`·`data-team-done`/`-plan`·입력 이름 `team_done`/`team_plan` 유지(95-192 시험·JS 호환). 템플릿 안에 「조건으로 감싸지 말 것」 주석을 남겼다.
- 그대로 둔 것: 「조직을 선택하세요」(`NeedOrg`, 조직 없음) 화면 — 보고서 자체가 없다. 엑셀·HWPX(내용 있을 때만 「팀 전체」 줄)·저장 형식·집계.
