# 95-91 업무 관리 상단 버튼 → 드롭다운

## 0단계: ViewGroupToggle
`attachViewGroup` 은 **항상** `ViewGroupToggle=true` 이다. 소속 업무 그룹이 없어도 토글이 나왔다.  
이번 건은 업무 관리 화면에만 `ShowGroupDropdown = ViewGroupToggle && userHasWorkGroup(c)` 를 붙였다. `member_group_ids`/`leader_group_ids`(기존 `injectGroupMaps`)가 비면 그룹 드롭다운을 숨긴다. **다른 화면의 `view_group_toggle` 동작은 그대로**다.

## 변경 파일
- `server/web/templates/_partials/ui_dropdown.html` — 공용 `ui_dropdown`
- `server/web/static/js/ui_dropdown.js`
- `server/web/templates/workboard/_board_toolbar.html` — 범위·그룹·접수/조치·보기·새 업무 순서
- `workboard/_board_head.html`, `board_list.html`, `board_kanban.html`
- `server/internal/handler/workboard_board.go` — `attachBoardDropdowns` (기존 MineHref/AllHref/ListHref/CalHref/KanbanHref, `?scope=with|personal`)
- `view_group.go` — `userHasWorkGroup`만 추가. `attachViewGroup` 조건은 안 바꿈
- `input.css` + `web/static/vendor/tailwind.css` (`.ui-dd*`)
- `layout/base.html`, `renderer.go`

## 컴포넌트 사용
```
{{template "ui_dropdown" .ScopeDrop}}
```
`ScopeDrop`/`GroupDrop`/`ViewDrop` 은 `{ID, Label, Current, Items:[{Value,Label,Hint,Href,Selected}]}`. 항목은 `<a href>`.
