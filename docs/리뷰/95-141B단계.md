## 원인

`school_site_register.js` `register()`는 `FormData`로 `customer_id`를 여러 개 보내 `multipart/form-data`가 된다.  
`SitesAddSchools`는 `ParseForm()` 후 `Request().Form["customer_id"]`를 읽었고, `ParseForm`은 multipart 본문을 읽지 않아 ids가 비고 added=0·skipped=0이 됐다. 기존 HTTP 테스트는 `url.Values`(urlencoded)만 보내 통과했다.

---

## 수정

1. `formNamedIDList`가 `c.FormParams()`로 urlencoded·multipart 모두에서 값을 읽는다.
2. `SitesAddSchools`는 그 목록을 쓰고, 받은 고객이 0건이면 **400** 「선택된 항목이 없습니다」(200 + 조용한 0건 금지). 화면은 기존 `!res.ok` 실패 모달.
3. 같은 패턴(ParseForm 후 Form/PostForm + fetch FormData)을 grep 후 함께 고침:
   - `POST /maintenance/:id/month-targets` (`customer_id` / `region`) — `plan_manage.html`
   - `POST /maintenance/:id/month-targets/bulk` (`target_id`) — 같은 화면
   - `as_action_sets` `leave_same` — `as_action_sets.js`
4. 95-141A `addedIDs` 기반 「등록됨」 표시는 그대로 유지.
