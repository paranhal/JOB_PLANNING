# 95-70단계 ②~⑤ — 업무 회의 통합 화면

기준: 채팅 지시(저장소에 지시서·시안 HTML 없음). §9 우선. VERSION 유지 `95-73`. 마이그레이션 없음. 배포 이미지 없음.

선행 ①: 메뉴만 `/meeting/board`. 이 단계에서 조회 화면·엑셀·인쇄·테스트.

## 열린 질문 (지시서 기본값으로 진행)

| 항목 | 기본값 | 결과 |
|------|--------|------|
| 일반 팀원 조회 범위 | 본인만. 기존 「그룹 포함 / 개인만」 토글은 두고, 팀 전체를 열지 않음 | `meetingTeamScope` 없으면 `meetingSelfKeys`. HTTP: 기술 계정에 `R2610-T01`만, `R2610-S01`·타 조직 없음 |
| 종류별 접수/조치 필드 | AS: 예정일+증상 / 완료일+상태. 정기점검: 방문일+제목 / 완료일+상태. 작업·영업·일반·지원: `work_date`(없으면 `due_date`)+제목 / `complete_date`+상태 | `boardReceiptText` · `boardActionText`. 링크는 기존 `Href`, AS는 `asHref` |
| `/meeting?date=` | 예전 일일 화면 유지 | ①과 동일. 새 기간은 `/meeting/board?from=&to=` |

## 구현 요약

- **조직별 보기:** C-Level 조직 탭(전체 조직 + `orgs` 목록, 시드 기준 도서관/미디어/SI). GET만. `POST /meeting/board` 403 「조회만」. 조직관리자는 소속 고정(`#meeting-board-org-locked`), `view_org_id` 우회 불가. 비전관리자는 `<select id="meeting-board-view-org">`.
- **보기 3종:** 담당자별(기본) · 사업별 · 주간 회의 자료표(읽기 전용). 「주간 자료 함께 보기」.
- **사업별:** 사업명 + 담당자 명단. `WorkListItemKey`로 한 건은 한 사업에만 집계.
- **휴가:** `staff_leaves` 기간 목록 + 담당자 행 `휴가` 배지.
- **정기점검 집행:** 대상·완료·미완료·지연·미배정·집행률.
- **패널:** 표시 체크, 접기/펼치기, 모두 펼치기/접기 (Alpine).
- **엑셀:** `/meeting/board.xlsx` 요약·상세. **인쇄:** `print=1` + `.no-print`. **95-67** `page-back`. **95-68** `data-table-cols="meeting_board"`. **95-69** `grid-cols-1` · `overflow-x-auto` · `min-w-[320px]`.

## 정기점검 집행률

도서관 대시보드·주간보고와 같은 월 집계.

| 칸 | 정의 |
|----|------|
| 대상 | `CountMonthMntQuota`(사이트 월 방문 목표. 설정 0이면 그 달 예약 건수) |
| 완료 | `CompanyMntMonthProgress` 누적 완료(월초~해당 주 끝) |
| 미완료 | max(0, 대상−완료) |
| 지연 | 기간 목록 중 정기점검·미완료·예정일 &lt; 오늘 |
| 미배정 | 기간 목록 담당 공란 + 그 달 `maintenance_month_targets` 중 방문 없는 건 |
| 집행률 | `ProgressPct(완료, 대상)`. 대상 0이면 `—` (0% 아님) |

HTTP: `data-mnt-target` / `data-mnt-done` / `data-mnt-rate` 가 `CompanyMntMonthProgress(O01, 2026-10-21)` 와 같음.
