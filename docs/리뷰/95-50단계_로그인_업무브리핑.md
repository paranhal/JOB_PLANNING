# 95-50단계 — 로그인 후 「오늘의 업무 브리핑」 팝업

기준: `커서_작업지시서_95-50_로그인_업무브리핑_팝업_업무시작하기.md`  
선행: 95-49. 실행일: 2026-10-25.  
운영·개발 DB를 코드로 바꾸지 않음. 배포 이미지는 요청 시에만.

## 무엇이 바뀌었나

로그인 성공 직후 첫 홈(`/`, `/work`, 영업 대시보드)에서 **오늘의 업무 브리핑** 팝업이 한 번 뜬다.

- 직원(기술·영업·지원 등): **내 업무** 오늘 건수 + 미배치(날짜·시간 미정) 건수. 「업무 시작하기」→ `/workboard?new=1` (새 업무 등록 모달 자동 열림).
- 조직관리자·비전관리자: **현재 조직 전체** 오늘 일정 + 담당자 없는 업무(`CollectUnassigned`). 「업무 시작하기」→ `/meeting`. 날짜 미정은 카드에 섞지 않고 안내 줄에만 「날짜 미정 업무 N건」.
- 임원(`c_level`), 대리 입력(viewAs), HTMX, 영업 `GET /` 302 에서는 표시하지 않음. 302에서는 쿠키를 소비하지 않아 영업 대시보드에서 뜬다.
- 비밀번호 변경·프로필 강제 화면으로 가는 로그인도 쿠키는 발급하고, **그 화면 처리 후 첫 홈**에서 팝업(계정 화면 자체에는 없음).

## 건수 정의

| 역할 | 일일 업무 | 미배정 업무 |
|------|-----------|-------------|
| 직원 | 업무 관리 리스트 오늘 「총 N개」와 같음 (`collectBoardEntriesAuto`, 그룹 포함 기본, `auto` 없음=조회만) | 미배치 패널 `UnplacedN` |
| 조직관리자 | `ListScheduledOn` + `filterMeetingOrg` | `CollectUnassigned(org)` − `dismissedKeys` (배정 알림과 동일). 날짜 미정은 안내 줄만 |

타 조직 업무는 `filterMeetingOrg` / 개인 보드 범위로 제외. 비전관리자 전체 보기(`OrgAll`)면 전 조직 합계.

## 쿠키

- `login_briefing=1` 세션 쿠키(HttpOnly, SameSite=Lax, 만료 없음). 로그인 성공 시 발급, 팝업 표시 성공 시 소비, 로그아웃 시 삭제. 건수 조회 실패 시 소비하지 않고 팝업도 없음.
- `login_briefing_off=YYYY-MM-DD` 오늘 자정까지. `POST /login-briefing/off`(CSRF). X·바깥·ESC는 이번 로그인만 닫기.

## 배정 알림과의 관계

브리핑이 뜨는 요청에서는 `show_assign_notice_modal=false`. **`assign_notice_shown` 은 건드리지 않음.** 사이드바 뱃지 유지. 다음 홈 방문에서 기존 알림 모달이 뜬다.
