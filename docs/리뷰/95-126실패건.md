## F3·F4. 고객 Lookup 가드

- `TestCustomerLookupSQLHasNoOrgOrTopOnly`: `customer_lookup.go 에 org_id 조건이 있다`
- `TestCustomerLookupGuardFailsOnOrgFilterSample`: `실제 Lookup 이 양성 샘플과 같이 org/최상위 조건을 가졌다`

가드는 파일 문자열에 `org_id`가 있으면 무조건 실패한다. 현재 코드:

```go
// CustomerQuery.OrgID — 비면 조직 조건 없음(95-2E). 사업 사이트 후보만 사업 조직을 넣는다
if org := strings.TrimSpace(q.OrgID); org != "" && org != OrgAll {
    b.WriteString(` AND c.org_id=?`)
}
```

95-22·95-2E: 선택 목록에 **기본** 조직 필터·최상위만(`has_parent=0`)을 넣지 말 것.  
95-124: 사업 사이트 후보만 `OrgID`를 **옵션**으로 넣음. `has_parent=0`은 Lookup에 없음.

가드가 「문자열 org_id 금지」로 남아 옵션 필터와 충돌한다. 콤보 기본 호출(`OrgID` 빈 값)은 여전히 전사다. 빠른 견적 고객 칸은 `customer_combo` Scope site이며 이 가드 실패와 별개로 HTTP T4는 통과했다.

고칠 때: 기본 경로에 `AND c.org_id=?`가 **항상** 붙는지 검사하고, `q.OrgID != ""`일 때만 붙는 분기는 허용. `has_parent=0` 금지는 유지.
