## 2-1. 저장 클릭 POST 미발생 (1-A-1)

**확정은 아직 아님.** 95-128은 MCP 클릭에서 POST 0건, `Alpine.save()` 직접 호출에서만 POST 400.

### 가설 (코드 우선)

1. **HTML5 제약 검증이 submit를 막음** — `customer_combo` `Required=true`로 hidden `customer_pick`에 `required`. `x-show="!newCust"`로 가려도 DOM에 남음. 스펙상 `type=hidden`은 검증 제외이나, 콤보 검색칸이 비어 있는 채 제출되면 브라우저가 submit 이벤트를 안 띄울 수 있음. `@submit.prevent="save()"`는 submit가 나와야 실행됨.
2. **신규 체크가 Alpine에 안 반영** — 체크박스에 `name` 없음. `new_customer`는 hidden `:value="newCust ? '1' : ''"`만. `newCust===false`면 POST가 나와도 기존 고객 분기(400 `고객, 수신인…`). 95-128 400 문구는 **이 분기**.
3. **MCP 클릭 ≠ 실클릭** — 버튼 `type="submit"`(152행)은 정상. 도구가 버튼을 못 누르면 POST 없음.

`element.click()`/`save()` 직접 호출은 통과로 치지 않음.

### 확정 방법 (§1에서)

PORT=18129 빈 DB. 네트워크 로그로 `POST /sales/quick-quote`만 센다.

1. 실클릭(좌표) · 저장 버튼에서 Enter.
2. 같은 입력으로 Playwright `locator('button[type=submit]')` 실클릭(JS invoke 금지).
3. 안 나가면 CDP `form.checkValidity()` / `validationMessage`(진단만).

## 2-4. 부가세 `totals()` vs 서버·xlsx (1-A-4)

화면 `quick_quote.html` 243–252행. VAT 별도·총액·`round==='none'`일 때:

`vat: … (this.round==='none'?supply: …)` → **부가세=공급가**. T7 화면 부가세 51,000의 원인.

서버: `model.ComputeQuoteTotalsScoped` / `ComputeQuoteTotalsFromBase` (`quote.go`). VAT 별도: `Supply=sum`, `VAT=sum/10`, `Total=ApplyRoundRule(Supply+VAT)`. `round=none`이면 VAT=공급가/10.

xlsx: `quote_xlsx_more.go`가 `q.Totals()`(같은 함수). 상세 `quotes.go` `CutLabel`도 동일.

**화면 JS만 어긋남.** 8조합 테스트는 서버 식 기준으로 화면·상세·xlsx를 맞출 것. 기존 `TestQuoteCutT7Thousand`는 서버 천원·총액만.
