## 3. 남은 질문
1. JS 파일 안의 `import`/동적 로드(다른 JS를 다시 불러오는 체인): `web/static/js` 의 화면용 JS(테스트용 `95_*.mjs` 제외)에서 `import`·`import()`·`createElement('script')`·`importScripts` 를 찾아봤으나 **없다**. 체인으로 옛 파일이 캐시될 경로는 현재 없다(후속 점검 불필요, 다만 새 JS에 import 를 넣을 때는 같은 가드가 잡지 못하므로 주의).
2. 배포 직후 이미 옛 `weekly-link.js` 를 캐시한 브라우저는 새 HTML 이 새 `?v=` 주소를 가리키므로 보통 강력 새로고침이 필요 없다. 안 켜지면 Cmd+Shift+R.
