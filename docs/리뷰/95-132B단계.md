## ① 모달

원인: `e6afaca`가 `x-cloak`를 Tailwind `hidden`으로 바꿈. Alpine `x-show`는 열릴 때 인라인 `display`를 지울 뿐이라 `hidden`의 `display:none`이 이긴다.

한 일:

- `_new_work_modal.html`에서 class `hidden` 제거.
- 초기 숨김은 전역 `[x-cloak] { display: none !important; }` + `x-cloak` (인라인 `style=`는 UI 린트 증가 금지).
- `@click.self="closeNewWork()"`.
- `syncNewWorkDialog()`로 두 번째 열림에서 `display:flex`를 맞춤.
- `data-new-work-dialog`.

사용 위치: 보드 셸(`_board_scope` → 일정표·칸반·요약 DOM), `live_work_modals`(BoardShell이 아닌 예전 칸반·업무 상세). 요약 버튼은 「+ 업무 시작」 링크, 모달 DOM은 끼워넣기용으로 남음.

브라우저 일정표 일·칸반:

| 동작 | 결과 |
|------|------|
| 「+ 업무 등록」 | `display:flex`, 닫기 버튼 보임 |
| 닫기 | `newWorkOpen=false`, `display:none` |
| 다시 열기 | `display:flex` |
| ESC | 닫힘 |
| 오버레이 클릭 | 닫힘 |

T1 일정표 일 마크업, T2 칸반, T3 주·예전 칸반, T4 템플릿 `x-show`+class token `hidden` 금지, T5 요약은 「+ 업무 시작」만.

## ② 0단계 — 390px에서 main보다 넓은 자식 상위 3

측정: `PORT=18140`, `innerWidth=390`, `main#main-content`. 래퍼(`board-root`/`board-layout`/`board-main`)는 제외하고 실제 폭 원인.

| 화면 | main SW | 1 | 2 | 3 |
|------|---------|---|---|---|
| 요약 일 | 540 | `section.card` 515 | 헤더 `flex … justify-between px-6 py-4` 515 | 보기 세그 `flex shrink-0 flex-wrap … gap-2` **491** (`cw=491`) |
| 요약 주 | 540 | 동일 card 515 | 동일 헤더 515 | 동일 `shrink-0` **491** |
| 요약 월 | 540 | 동일 | 동일 | 동일 491 |
| 일정표 일 | 540 | 동일 card 515 | 동일 헤더 515 | 동일 491 |
| 칸반 | 540 | 칸반 열 `flex gap-3 overflow-x-auto` **1348** (자체 가로 스크롤) | card 515 | 헤더 515 |
| register 일 | **390** | (400 초과 자식 없음) | | |

공통 원인: 보드 헤드의 `shrink-0` 세그+버튼 줄이 내용 폭 491px라 `main`이 540으로 늘어남. 칸반 열 줄은 이미 `overflow-x-auto`. register는 넘치지 않음.

확인 후: 해당 헤드에 `min-w-0`·`flex-wrap` 또는 세그 줄만 `overflow-x-auto`. 칸반 열 줄은 이미 자체 스크롤.
