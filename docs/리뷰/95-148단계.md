# 95-148 업무 수정: 거래처 유지 · 사이트 연결 사업 · 종료일 오류 문구

작성: 2026-11-08. 브랜치 `wip/95-정리-백업`. 배포·push 없음.

## 0단계 (코드 변경 전, 운영 DB 미접근)

① **WT-3465 행은 운영 DB를 읽지 않음.** 코드 경로만.

- 종료일 빈 값 + `status≠inbox` → `UpdateTask`가 `?err=task`. `visibleQueryErr`는 「겹칩/다른 업무가 있습니다」만 통과 → `FlashErrMsg` 공란 → 배너에 코드 `task`.
- 행정/지원(`IsAdminGTDTask`)은 빈 `DueDate`를 시작일로 채우지 않음.
- 거래처: `GetTask` JOIN으로 표시명(`OrgName`/`CustomerLabel`)은 있음. 콤보 `restore()`는 `/lookup/customers?scope=site&include=ID&limit=8` — INCLUDE가 OR이어도 **이름순 LIMIT 8**에 안 들면 못 찾음 → `selectedId` 지움. `applyCustomerForm`은 ID가 있으면 `customer_name`을 비움.
- `scope=site` 소속·최상위 조건은 이번엔 **안 바꿈**(조회 실패는 KeepMiss+서버 라벨로 우회).

② 같은 증상(거래처 ID는 있는데 `scope=site` 조회에 안 잡힘) 건수 제안 쿼리(실행 금지):

```sql
-- include+LIMIT8 절단 가능: 활성 site 고객인데 org_name 순 8건 밖
SELECT COUNT(*) FROM work_tasks t
WHERE TRIM(COALESCE(t.customer_id,'')) != ''
  AND COALESCE(t.source_type,'') = ''
  AND t.work_type IN ('admin','support','sales','');

-- party_kind가 site 범위가 아닌 거래처
SELECT COUNT(*) FROM work_tasks t
JOIN customers c ON c.customer_id = t.customer_id
WHERE TRIM(COALESCE(t.customer_id,'')) != ''
  AND COALESCE(c.party_kind,'customer') != 'customer';
```

③ 종료일 빈 업무:

```sql
SELECT COUNT(*) FROM work_tasks
WHERE TRIM(COALESCE(due_date,'')) = ''
  AND status != 'inbox'
  AND COALESCE(recurrence_role,'') != 'parent';
```

④ `ProjectPickerOpts`: `UseSiteProjects`, `SiteCustomerID`, `ShowSiteNote`, `HideOther`, `AllowQuickRegister`. 144B 조치는 `ListBySiteCustomer` + 안내. 144D 점검은 사이트 목록에 **org 사업을 합침**. `project_sites`(project_id, customer_id, is_active, UNIQUE). 148은 **SiteOnly**로 org 합치기·타 부서 보기를 쓰지 않음.

## 구현

일반 업무 수정(`/workboard/tasks/:id/edit`)만.

- 거래처: 서버 `CustomerLabel` + `KeepMiss`. restore 실패 시 ID 유지. ✕/입력 시에만 변경. 변경 시 사이트·사업 후보 갱신.
- 사업: `project_sites` 활성 등록 합, 한 줄 1사업 전부, 자동 선택 없음. 0건이면 검색 → 확인 후 `POST /workboard/projects/link-site`만 INSERT. 기존 `project_id`는 「현재 연결」. 타 부서 보기 숨김. 지원업무 필수 유지.
- 종료일: `err=due_date` + 「업무 종료일을 입력해 주세요」, 칸 강조·스크롤, 「시작일과 같게」, 미정+사유. **자동 채움 없음.** 겹침 문구 경로 변경 없음.
