# 95-181 구현 보고 — 주간 보고서 「금주에 넣기」·「차주에 넣기」 (입력 통합 A안)

작성: 2026-11-12. 사용자 결정: A안(버튼으로 칸 끝에 추가, 덮어쓰지 않음). 사용자 추가 지시: 기존 사업별 연동 로직은 그대로 둔다.

## 구현 (커밋 3e33ea0)
- `model.WeeklyInputLines`: 수행 구조 진행에서 금주·차주 줄을 만든다. 금주 = 완료한 곳수가 있는 작업 계획·수량만 하부 업무(「홍천 지역 10곳 중 4곳 완료(40%)」), 차주 = 남은 곳수(「홍천 지역 남은 6곳 진행」, 착수 전이면 「횡성 지역 5곳 착수」). 분모 0 이면 줄이 없고, 한 번에 5줄까지. 줄 앞에 「- 」.
- `ProgressLines`가 같은 계산에서 줄을 함께 돌려주므로 새 산식은 없다(진행 문장과 같은 함수).
- 주간 보고서 사업 카드: **편집 모드에서만** 「금주에 넣기」·「차주에 넣기」 버튼. 눌러도 DB에는 안 남고 칸에만 추가되며 저장은 사용자가 한다.
- 칸 끝에 추가만 한다. 이미 있는 줄(앞의 「- 」·공백 차이 무시)은 건너뛰고 「이미 들어 있습니다」로 알린다.

## 바꾸지 않은 것
사업별 카드 머리의 진행 문장과 「복사」 버튼, 사업으로 줄 만들기, 사업 연결, 업무 회의 사업별 보기, 저장한 주간 본문, 「다시 집계」.
