# 95-64단계 — 제품군 관리 화면 (제품분류·제품구분·세부제품군)

선행: 95-63. 실행일: 2026-10-26. **§9:** 95-63 제품분류 탭·SPC007~012는 유지(동기화 키). 더 확장하지 않음.

## 한 일

- `product_classes` / `product_groups`(PG-####, 재사용 금지), `assets.product_group_id`.
- 시드 16건 시안 그대로. PG-0003 **전선스위치**.
- `SyncAssetLegacyFromGroup` 한 함수로 type/category 채움. 컬럼 제거 금지.
- 백필 1회·멱등. category/type만. 미매칭 NULL. 화면 상단 미분류 건수.
- 관리: 비전(전사)만. 자산 폼 3단 선택은 로그인 사용자(자산 쓰기).
- 미등록 행 첫 세부 채움(번호 유지). 이후 새 번호. 구분 이름·분류 일괄 반영.
- 사용 중 삭제 불가→사용중지. 미사용 삭제·일괄 삭제.
- 열 너비 드래그·더블클릭·초기화·localStorage. 표는 열 폭 합(px), `overflow-x:auto`, 넓은 핸들.
- 엑셀: 양식 → 미리보기 → 확인 후 등록. PNG 없음.
- 설치자산 업로드 「제품분류」→「제품군」(옛 머리글도 읽음).
