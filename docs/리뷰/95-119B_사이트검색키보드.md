## 동작

마우스 `@click="pick(s)"` 유지. Enter·↑↓·Esc 추가.

| 키 | 동작 |
|----|------|
| Enter | `preventDefault` 후 강조 항목 추가. 후보 1개면 그 사이트, 여러 개면 첫 항목 또는 ↑↓로 고른 항목. 0개면 추가 없음. 부모 폼 미제출. |
| ↑ / ↓ | 후보 강조(`combobox-option-on`), 순환 |
| Esc | 후보만 닫음(`.stop` — 모달 전체 닫지 않음) |
| 클릭 | 기존과 같이 `pick(s)` |

추가 후 `q`·`cands` 비우고 검색창 포커스 유지(`x-ref="siteQ"`). 중복·상한(업무 100 / AS 기본 20) 기존 안내 유지.
