## 동작

일·주·월 캘린더 막대/칩과 리스트 담당 칸에 **사람 이름**을 넣는다. 공용 필드 `AssigneeLine`(부분 템플릿 `board_assignee_line`, `data-assignee-line`).

- 주담당 이름. 참여자가 더 있으면 `외 N명`, `title`에 전원.
- 담당 없음 또는 `USR-…` 고유번호만 있으면 **미배정**(95-74와 같이 고유번호는 화면에 안 냄).
- 끼워넣기 구간 조각(1/2, 2/2)에도 같은 줄을 붙인다.
- HTML 이스케이프는 템플릿 기본 이스케이프.
- **내 업무**에서도 이름을 숨기지 않는다. **전체**에서는 각 업무 담당자가 보인다.
- 월 보기 칸은 기존처럼 최대 3칩(+N건). 좁은 칸은 `truncate`·`min-w-0`.
- 건수는 기존처럼 업무 건. DB 스키마·운영 데이터 변경 없음.

## 기본값

| 항목 | 이번 기본값 |
|------|-------------|
| 내 업무에서도 이름 | **표시** (본인이라도 숨기지 않음) |
| 담당 없음 | **미배정** |
| 여러 명 | 주담당 + **외 N명** (N = 표시 가능한 이름 수 − 1) |
| `USR-` 고유번호 | 이름이 아니면 **미배정** |
| 월 칸 | 기존 3칩 상한 유지, 칩 안에 이름 |
| 360px 월 | 칩은 `lg` 이상에서만 보이던 기존 밀도 유지. HTML에는 이름 포함. 일·주는 360/390에서 줄이 보임 |
