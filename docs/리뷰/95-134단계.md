## §1-D 보고: 시기(`expected_ym`)가 비어 있는 사업의 표시

코드 변경 없음. 필드 기준은 등록 「사업 시기」=`sales_projects.expected_ym`(95-134 `SalesMissingInfo`의 「시기」와 같음).

### 목록 `/sales`

| 보기 | 빈 시기 |
|------|---------|
| 표 (`display=list`) | `PeriodLabel()`이 빈 문자열 → 칸에 `—`. 정렬 키 `period`는 빈 문자열이 앞으로(오름)/뒤로(내림) |
| 타임라인 | `BuildSalesTimelineAxis`: `Unscheduled=true`, 전용 「미정」 열에 배지. 월 칸에는 안 붙음 |
| 칸반 | 단계는 그대로 표시. 카드 정렬만 `ExpectedYM` 빈값. 시기 열 없음 |
| 「보완 필요」 | 시기가 비면 `ListNeeded()`에 포함(고객 등과 OR). 파이프라인 화면에는 이 필터 없음 |
| 필터 `period=` | 연·분기·월을 고르면 `expected_ym LIKE/구간`. 빈 시기는 **빠짐**. 필터 「전체」면 남음 |
| 그룹 화면 from~to | `expected_ym` 구간. 빈 값은 `'' >= from`이 거짓이라 **빠짐** |

### 파이프라인 `/sales?view=pipeline`

- 기본 집계 기준은 **매출 시기**(`revenue_ym`). 화면 기준을 「사업 시기」로 바꿔야 `expected_ym` 공란이 「시기 미정」이 된다.
- `BuildSalesForecast`: 선택한 기준 YM이 비면 `Unsched=true`. 요약 「시기 미정 N건 · 금액」, 표 기준 시기 `—`, 행렬 **미정** 열. 월 칸에는 안 더함(범위 밖 YM과 같음).
- 기본 From~To는 이번 달~+11개월. 「시기 모두 보기」(`all_ym`)는 템플릿 체크만 있고 **집계 From/To를 바꾸지 않음**. 미정 건수는 요약에 그대로 잡힌다.
- 휴면·실주·중단은 예측에서 제외(기존). 엑셀도 `Unsched` 동일.
- `BuildSalesPipeline`(대시보드용 월 버킷)은 **사업 시기** 기준. 빈 값은 버킷 키 `unscheduled`, 라벨 「미정」, 월 정렬 맨 뒤. 단계 합계·가중에는 **포함**.

HTTP 회귀: `TestSalesHTTP_KanbanTimelinePipelineAndActivityBoard`가 빈시기·짧은시기 사업을 파이프라인 HTML에 넣는지 확인함.

### 통계(영업 대시보드 `/sales/dashboard`, 업무 통계는 해당 없음)

| 지표 | 빈 사업 시기 |
|------|----------------|
| 진행 건수·단계 막대·가중 파이프라인 | **포함**(단계·금액만, 시기 불필요) |
| 이번 달 수주 | `WonAt`(없으면 `UpdatedAt`) 월. 사업 시기와 무관 |
| 주요 사업기회 | 목록과 같이 기간 라벨이 비면 빈칸/`—`에 가깝게 보임(파이프라인 월 버킷 「미정」과는 별개) |
| `stats/` 업무 통계 | 영업 `expected_ym`을 쓰지 않음 |

### 정리

사업명만 등록하면 목록·칸반·대시보드 단계 합에는 보인다. 시기를 고르는 필터·행렬 월 칸에서는 빠지거나 「미정」으로만 모인다. 파이프라인 기본 화면의 「시기 미정」은 **매출 시기** 공란이다. 보완 필요 목록의 「시기」와 축이 다르다.
