## 동작

- 공용 부분 템플릿 `work_segments_form`: 구간 표, 합계(이동 제외), 「여기에 다른 업무 추가」, `seg_shift`/`seg_merge`/`seg_date` 확인.
- 적용: AS 조치, 하부 업무 조치, 정기점검 방문 조치, 작업 조치, 행정/지원 상세(`task_show`).
- `EnsureMaintenanceTasksBetweenForOrg` / `applyMntTaskLink`: 저장 구간이 있으면 업무 시각을 방문값으로 되돌리지 않음. 구간이 더 넓으면 방문 시작·종료를 맞추고 비고에 「끼워넣기로 시간 조정」.
- `ReconcileASDailyTasks` / `SyncASDailyTask`: 저장 구간이 있으면 예정일만으로 `work_date`를 덮지 않음. 구간 행은 지우지 않음.
- 일정 배치·계획 수정 날짜 변경: `applyDateMoveToSegments` + `PlaceTask`/`ShiftSegmentDates`.
