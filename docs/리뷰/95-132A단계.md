## ① 「+ 업무 시작」→ 모달만 열리고 `display:none` — 원인

### 버튼·핸들러 (요구와 불일치)

`_new_work_modal.html` `board_new_work_btn`: 요약·일정표·칸반 **같은 버튼**이 `@click="openNewWork()"`만 호출한다.

```1:4:server/web/templates/workboard/_new_work_modal.html
{{define "board_new_work_btn"}}
{{if .CanWrite}}
<button type="button" ... @click="openNewWork()" data-new-work>{{if eq .Display "summary"}}+ 업무 시작{{else}}+ 업무 등록{{end}}</button>
```

- 라벨만 Display로 갈린다. **이동 URL이 없다.**
- `openNewWork()`(`boardNewWork()`, `#board-root`의 `x-data`)가 `newWorkOpen=true`로 둔다. 서버 라우트·`parseBoardDisplay`는 개입하지 않는다.
- 95-132 §5-D·이번 1-A: 요약의 「+ 업무 시작」은 모달 없이 `view=sched&range=day&date=<선택일>`로 **push**. 현재 `parseBoardDisplay`에 **`sched` 별칭이 없다**(일정표는 `view=day`/`list`).
- 읽기 전용은 `CanWrite`라 버튼 전체 숨김 → 스펙상 「+ 업무 시작」(이동)은 보여야 한다.

### Alpine·가시성 (`newWorkOpen=true`인데 안 보임)

모달: `x-show="newWorkOpen" x-cloak`. CSS는 head와 `@layer utilities` 모두 `[x-cloak] { display: none !important; }`.

T9 실측: `#board-root._x_dataStack[0].newWorkOpen === true`인데 `[aria-labelledby=nw-title]`의 `getComputedStyle.display === "none"`, 닫기 버튼 `offsetParent` 없음. Escape는 `closeNewWork()`로 상태는 꺼짐.

유력 원인:

1. **`x-cloak`가 안 지워지면 `!important`가 `x-show` 인라인 display를 이긴다.** 상태가 true여도 화면은 none.
2. 모달은 `#board-root` 안(`board_shell_close` → `wb_new_work_modal`). 일정표·칸반은 **안쪽 또 다른 `x-data`**(pick/place, 칸반 이동). 요약은 그 중첩이 없다. 버튼은 `board_cal_head`에 있어 요약에서는 `boardNewWork` 스코프가 맞다.
3. 두 번째 모달(`_live_modals.html`)은 `BoardShell=true`라 board에서는 **안 그린다.** 중복 ID는 board 경로의 주원인이 아님.
4. 일정표·칸반의 「+ 업무 등록」도 **같은** `openNewWork()`라, 1-A에서 요약 버튼을 링크로 바꿔도 **등록 모달이 계속 `x-cloak`면 T9 팝업은 그대로 실패**한다.

구현 방향(확인 후): 요약 버튼은 `<a href="...view=sched&range=day&date=...">`(push). 등록 모달은 `x-cloak` 잔존을 제거하고 실제로 보이게. `sched`를 `parseBoardDisplay`에 일정표 일로 매핑.
