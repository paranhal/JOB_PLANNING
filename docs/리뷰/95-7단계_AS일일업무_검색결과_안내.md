## 동작

- 선택 목록은 기존처럼 **열린·미배치 AS**만. 「대기 중인 AS가 없습니다」는 후보가 전혀 없을 때 유지.
- 검색어 2글자부터 `GET /workboard/as-lookup?q=` (현재 조직, 최대 20건, 고객명·접수번호·증상, LIKE 이스케이프).
- 선택 가능한 건이 있으면 안내 박스를 열지 않음(기존 select).
- 해당 AS가 이미 일정표에 있으면 「이미 일일업무로 등록된 AS입니다」 + 접수번호·담당자·일시 + `/workboard/tasks/:id`.
- 완료/종료/취소/행정지원이면 「완료된 AS입니다(상태)」 + `/as/:id`. 선택은 불가.
- 타 조직은 존재하지 않음과 동일(힌트만, 항목 0).
- 맞는 AS가 없으면 「AS가 존재하지 않습니다.」 + **[추가][확인]**. 고객명이 현재 조직에서 정확히 1곳이면 `/as/new?customer_id=`. 그 외 `/as/new`. 읽기 전용·C-Level은 [추가] 없음(`canReceiveAS`). [확인]은 안내를 닫고 검색 칸을 비움.
- 입력 값이 있는 채로 [추가]면 「입력 중인 내용이 사라집니다」 확인.
