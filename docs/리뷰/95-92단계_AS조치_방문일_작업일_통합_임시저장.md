# 95-92 — AS 조치 방문일=작업일 통합 · 결과 없이 임시 저장

## 원인 (§1과 실제)

지시서 §1과 같다.

1. `_action_set.html`에 방문일(`visit_date`) 칸이 작업일(`work_date`)과 따로 있었고, `parsePostedSet`가 둘을 연결하지 않았다. `actionSaveMissingErr`는 `VisitDate`만 봐서 작업일을 채워도 「현장방문이면 방문일을 입력하세요」가 났다. 접수 본문 `as.go`가 세트에서 복사한 방문일을 빈 `visit_date` 폼으로 덮어쓸 수도 있었다.
2. `saveSet()`이 결과 없으면 서버에 보내지 않았고, `SaveActionSet`도 `result_code`를 항상 요구했다.

- 접수 본문 `visit_date`는 통계·기존 저장을 위해 **hidden 미러**로 남김(입력 칸은 없음).
