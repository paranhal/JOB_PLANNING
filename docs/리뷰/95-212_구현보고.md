# 95-212 구현 보고 — 주 1차 자동 마감(금 24:00) · 마감 표시 · 23:55 안내 띠

> **요약(배포 판단용):** 마감 스케줄러와 화면 표시를 구현했다. 마감은 **이미 작성된 내용·상태를 바꾸지 않고** `close1_at`/`close1_by` 두 키만 JSON `extra`에 더한다. 보고서가 없는 조직만 자동 집계로 새로 만든다. 마이그레이션 없음.
> **지시서 §2(전주 업무 금주 반영)는 95-213 규칙표로 대체**되어 이 보고서 범위에서 빠졌다(95-213_구현보고.md 참고).

## 2. 동작 규칙
- 마감 시각 = 보고 주 W(월)의 금요일 24:00 = 토요일 00:00 KST. 예: 11/9 주 → 11/13(금) 24:00.
- 대상: 활성 조직 전체(`all` 제외). 이번 주만. **재시작 따라잡기도 이번 주만**, 지난 주는 건드리지 않는다.
- 보고서 없음 → 자동 집계로 생성(작성 중, 작성자 `system`) + `close1_at`. 있음 → `content_json`에 마감 키만 추가. **상태·확정자·확정시각·수정자·수정시각 불변**, 줄·팀 전체·지원 필요·주요 의사결정 불변(재집계 안 함).
- 중복 실행 방지: 이미 `close1_at`이 있으면 건너뜀. 갱신은 `WHERE content_json=<읽은 값>` 조건이라, 사이에 누가 저장했으면 0건 갱신 후 다음 주기에 재시도.
- 조직 단위 격리(한 조직 실패가 나머지를 막지 않음). 로그 + 감사 기록(`change_log`, 사유 created/marked).
- 마감 후에도 편집·저장·다시 집계·확정은 막지 않는다. 마감 뒤 저장해도 `close1_at`은 유지된다.
- 화면: 마감 전(이번 주) `1차 마감 11/13(금) 24:00 · 남은 시간 …`, 마감 후/기록됨 `1차 마감됨 …`(+쓰기 권한자에게 「다시 집계」 안내). 기록 없는 과거 주·미래 주는 표시 없음.
- 안내 띠: 쓰기 권한자가 화면을 열어 둔 상태에서 마감 5분 전부터 「자동 집계 예정이니 저장 버튼을 눌러 데이터를 저장하세요」 + mm:ss 카운트다운, 마감 시각이 지나면 「1차 마감되었습니다…」로 전환. **서버 시각 기준**(`data-server-now-ms`로 브라우저 시계 차이 보정). 읽기 전용 사용자는 안내문만(띠 없음).
