# 95-190 구현 보고 — 주간 업무 보고서: 기본 편집·고정 저장 막대·엑셀/HWPX 저장

작성: 2026-11-14. 푸시·배포·VERSION 변경 없음. 작업지시서 파일(95-190)은 찾지 못해 붙여 주신 지시문과 대화에서 정한 기본안·HWPX 추가 요청으로 진행했다. 지시서와 다른 점이 있으면 알려 주세요.

## 0. 확인 결과 (변경 전)
- 편집은 `?edit=1` 이고 `canEdit` 일 때만 켜졌다(작성 중/확정 상태는 판정에 쓰이지 않음).
- 주차 이동(‹ › 이번 주)·팀 탭 링크는 `week`·`org` 만 붙이고 `edit` 를 버렸다. 저장 폼에는 `edit` 숨은 입력이 없어 저장하면 항상 읽기 모드로 돌아갔다.
- 화면 출력은 엑셀뿐이었고 HWPX 는 휴가·AS 보고서에만 있었다.

## 1. 변경
### A. 기본 편집 (결정: 작성 중이면 편집, 저장 후 편집 유지)
- `weeklyEditOn`: `edit=1` 편집, `edit=0` 읽기, **값이 없으면 「작성 중」(저장 전 포함)이고 줄이 있을 때 편집**, 확정은 읽기. 편집 권한(`CanEdit`)이 없으면 항상 읽기.
- 주차 이동·이번 주·팀 탭 링크는 `edit` 를 붙이지 않는다(서버 기본에 맡김). 단 읽기(`edit=0`)로 보고 있을 때만 `&edit=0` 을 이어 간다.
- 저장 폼이 `edit=1` 을 보내고, 저장·다시 집계 뒤에도 편집 모드를 유지한다(`edit` 없는 기존 요청은 종전처럼 읽기). 확정·자동 생성은 기본 규칙을 따른다.

### B. 고정 저장 막대
- 편집 모드의 화면 아래에 막대(`data-weekly-savebar`)를 고정한다: 「수정한 내용이 없습니다 / 저장하지 않은 수정이 있습니다」, 「다시 집계」, 「저장」. 버튼은 `form="weekly-form"` 로 카드 폼과 연결해 폼 밖에 둔다(폼이 화면 아래에서 시작해도 막대가 항상 보이도록).
- 수정하면 문구가 바뀌고, 저장하지 않고 이동하면 확인(`beforeunload`)이 뜬다. 저장·다시 집계는 한 번만 제출된다.

### C. 넣을 줄 없음 안내
- 보고서는 있는데 사업·활동 줄이 하나도 없는 주차를 편집하면 「편집할 사업·활동 줄이 없습니다…」 안내(`data-weekly-no-lines`)와 「다시 집계」만 보인다(빈 저장 막대 없음).

### D. 엑셀 + HWPX 발표 요약 저장
- 저장 메뉴를 「엑셀·HWPX 저장」으로 바꾸고 「이 팀 발표 요약(HWPX)」, 전사 열람 권한에서 「전사 발표 요약(HWPX)」을 추가했다. 엑셀(`/export`)은 그대로.
- 새 `GET /stats/company-weekly/export-hwpx?week&org&scope`(`ExportWeeklyReportSummary`): 엑셀과 같은 보고서 자료(`weeklyExportViews`로 공통화)에서 만든다. 권한·조직 판정·감사 로그(다운로드 기록)도 엑셀과 같다. 줄이 하나도 없으면 파일 대신 오류 안내로 돌아온다.
- `internal/hwpx/summary.go` `BuildWeeklySummary`: 템플릿 없이 한글 12 기본 구조(`BuildPlaceholderTemplate`과 같은 패키지 골격)로 만든다. 문서 내용: 제목(팀 / 전사), 기간(년·월·주차·날짜), 팀 ■, 사업 ▶(담당자·고객), 「금주 추진내역」·「차주 추진계획」 줄, 지원 필요사항·주요 의사결정. 파일 이름 `주간업무발표요약_{팀}_{월일}_{n}주차.hwpx`(Chrome 이 막지 않도록 octet-stream).
- 한글 서식 원본(제출용 양식)이 있으면 `Replace` 방식으로 바꿀 수 있다. 지금은 기본 서식(굵게·표·페이지 나누기 없음, 줄 단위 문단)이다.

## 4. 한계·남은 것
1. **한글에서 열어 보지 못했다.** 이 환경에 한컴오피스가 없어 HWPX 는 구조·XML·zip 정합성만 검증했다(휴가·AS 보고서와 같은 골격을 써서 열릴 가능성이 높지만, 실제 한글 12 로 한 번 열어 확인해야 한다).
2. 발표 요약은 기본 서식이다. 회의용 제출 양식(표·로고·페이지 설정)이 있으면 양식 파일을 받아 자리표시자 치환 방식으로 바꿔야 한다.
3. 「전사 주간업무보고 파일에 추가…」(기존 후속 항목)는 그대로 남아 있다.
4. 브라우저 이동 확인은 저장하지 않은 수정이 있는 동안만 뜬다(저장 막대·링크 모두 같은 규칙).
