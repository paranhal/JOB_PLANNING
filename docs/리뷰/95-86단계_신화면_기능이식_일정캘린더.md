# 95-86 단계 A — 일정 캘린더 편집 기능 이식

## 결과
구화면 `/workboard/register` 의 배치 바 이동·담당자 열·조치/수정/내리기·지원 표시·지난날 잠금 UI·사업/그룹 필터를 신화면 `/workboard/board` 에 이식했다. 서버는 기존 `POST /workboard/schedule`, `/workboard/unschedule`, `/workboard/register/unlock-past` 만 사용한다.
