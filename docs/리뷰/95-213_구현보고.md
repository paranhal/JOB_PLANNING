# 95-213 구현 보고 — 업무 상태별 「금주 추진내역 / 차주 추진계획」 줄 규칙

> **요약(배포 판단용):** 완료가 아닌 일반 업무(진행 중·미완료·취소)가 금주 추진내역에 조치 요지와 함께 나오고, 차주에는 업무 계획이 있으면 계획 줄만, 없으면 이월 줄 한 번만 나온다. 줄 생성 한 곳(`company_weekly_status.go` → `composePrevBundleProg`/`composePlanBundleX`)에서 처리해 화면·엑셀·HWPX가 같다. 95-212 §2의 「진행 중」 줄은 이 규칙으로 일원화했다. 저장 형식 변경·마이그레이션 없음.

## 1. 0단계 확정(사용자 승인)
- **조치 내용:** 일반 업무 = `work_activities.content`(업무 상세 「조치 이력」, `created_at`이 실적 주 월~일), 사업 작업 = `work_tasks.action_taken`·`action_remark`(`action_start_at`이 실적 주). `complete_note`·`hold_next_action`은 쓰지 않음.
- **업무 계획:** ① 차주 구간에 일정이 있는 하위 일정, ② 차주 일정이 있는 미완료 세부 조치 항목(`work_actions`). 업무 자신의 차주 일정은 현행 계획 줄.
- 축약: AI 없음. 공백·줄바꿈 정리, 여러 기록은 `·`, 최대 80자(`weeklyActionMaxRunes`), 넘으면 `…`. 형식 `제목: 조치 요지(진행 중)` / `(취소)`, 날짜 생략.

## 2. 적용 전·후 (실적 주 11/9~11/15, 차주 11/16~)
| 사례 | 금주 (전 → 후) | 차주 (전 → 후) |
|---|---|---|
| (a) 완료 | `제목(11/9)` → 동일 | 없음 → 동일 |
| (b) 진행 중 + 조치 있음 | 없음 → `제목: 조치 요지(진행 중)` | `(이월)` → 계획 없으면 `(이월)` 1회, 계획 있으면 계획 줄만 |
| (b) 진행 중 + 조치 없음, 일정 실적 주 | 없음 → `제목(진행 중)` | 동일 규칙 |
| (c) 미완료 | (b)와 동일 | 동일 |
| (d) 일정 없음 + 조치 있음 | 없음 → `제목: 조치 요지(진행 중)` | 이월 |
| (d) 일정 없음 + 조치 없음 | 없음 → 없음 | 이월 |
| (e) 취소 + 조치 있음 | 없음 → `제목: 조치 요지(취소)` | 없음 → 계획(차주 하위·조치 항목)이 있을 때만 계획 줄 |
| (e) 취소 + 조치 없음 | 없음 → 없음 | 동일 |
| 조치가 실적 주 밖 | 조치 무시, 일정이 실적 주면 `제목(진행 중)` | 이월 |
