# 95-60단계 — 일정 화면 접수(계획)/조치(실행) 토글

선행: 95-59. 실행일: 2026-10-26. 배포 이미지는 만들지 않음.  
지시서 파일은 레포에 없어 채팅 요구사항 문장을 기준으로 구현했다.  
마이그레이션: 없음(표시 상태만 URL `show` + `localStorage jp.schedule.show`).

## §4 업무 종류별 접수/조치 기준

| 종류 | 접수(계획) 날짜 | 조치(실행) 날짜 | 같은 날 |
|---|---|---|---|
| 행정·지원·영업·작업 | `work_date`, 없으면 `due_date` | `complete_date`. 완료인데 비어 있으면 계획일 | 한 칩 |
| AS | 동기화된 일일업무 `work_date` | `complete_date`(AS 상태 반영) | 한 칩 |
| 정기점검 | `visit_date` | 완료이고 `completed_date`(없으면 `visit_date`) | 한 칩. 날짜가 다르면 둘 다 켜면 두 칸 |

기본 `show` 없음·빈 값·둘 다 끔 → **접수만**. 토글은 각각 on/off, 둘 다 켜기 가능, `ToggleScheduleShow`가 둘 다 끔을 `plan`으로 되돌림.

건수는 **현재 기간·필터 뒤, show 필터 전**. 꺼진 쪽 숫자도 항상 보인다.

## §5 날짜별 업무 화면 전수 조사

| 화면 | 경로 | 적용 |
|---|---|---|
| 일정 캘린더 월/주/일 | `/workboard/board?view=month\|week\|day` | **적용** 공통 `schedule_show_toggle` |
| 일일 업무 리스트 | `/workboard/board?view=list` | **적용** |
| 정기점검 일정 캘린더·칸반·목록 | `/maintenance/:id` | **적용**(보기 전환·월·담당자·오늘 링크에 `show` 유지) |
| 업무처리현황 캘린더/타임라인 | `/work-status` | 미적용 — 현황·누락 점검 화면 |
| 일일 업무 등록(예전) | `/workboard/register` | 미적용 — 등록 팔레트 |
| 업무 리스트(예전) | `/workboard/list` 등 | 미적용 |
| 관리 > 휴일 | `/admin/holidays` | 미적용 |
| 대시보드·통계 타임라인 | `/` `/stats` | 미적용 |
| 반복 업무 요일 격자 | 등록 모달 | 미적용 |
| 사이트 폼 점검 요일 | 고객/사이트 | 미적용 |
| 미계획 업무함 | `/plan/unplanned` | 미적용 — 날짜 축 목록 아님 |
| 영업 상세 일정 안내 | `/sales/:id` | 미적용 |

적용 화면 링크(월/주/일·이전/다음·리스트·정기점검 보기)는 `keep`/`QShow`로 `show`를 이어받는다. URL에 `show`가 없고 localStorage가 `plan`이 아니면 `schedule-show.js`가 한 번 치환한다.
