## 동작

- 점검 사이트 목록·등록 화면에 **「업종별 일괄 등록」**. `GET/POST /maintenance/sites/bulk` (`/:customer_id` 보다 앞).
- 업종 선택 → 활성 `party_kind=customer` · 해당 업종 · **아직 이 조직 사이트가 아닌** 고객. 기본 전체 체크. 타 조직 사이트는 회색 비활성 행 + **조직명만** (`「○○ 점검 사이트로 등록됨」`). 사이트 표시명은 노출하지 않음.
- 점검주기 필수(월/홀수격월/짝수격월/분기/반기/년1회), 회차 기본 1, 제품은 조직 마스터가 있을 때만. 지역은 고객 주소 → `ExtractKoreaRegion`(광역 약칭, 예 충남). 없으면 비우고 「지역 없음」.
- 체크된 것만 등록. 서버 재검증 실패는 건너뜀(전체 롤백 아님, DB 오류만 롤백). 이미 있으면 멱등 건너뜀. **방문·일정 자동 생성 없음.**
- 권한: 기존 사이트 등록과 동일(`adminOnly`). C-Level·읽기전용 POST 거부. view-as POST 403. vsadmin은 조직 미선택 시 「소속 조직을 선택하세요」. 조직관리자 타 조직 `org_id` 403. 사이트 `org_id` = 작업 조직.
- 상한 3,000. 감사: `logCreateWithReason` (`maintenance_site_config` / `bulk:{org_id}`).
- 건너뜀 엑셀: `GET /maintenance/sites/bulk/skips.xlsx`, `xlColor` 6자리 → 스타일 XML 8자리 FF+RRGGBB.

고객 `industry` 원 값은 **수정하지 않음.**
