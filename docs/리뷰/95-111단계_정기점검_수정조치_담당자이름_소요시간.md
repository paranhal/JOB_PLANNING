# 95-111 정기점검 수정·조치 화면 — 담당자 이름 · 소요시간

커밋 해시: **미커밋.** 워킹트리에 95-86 이후 다단계 변경이 한 작업본에 섞여 있어, 95-111만 떼어 커밋하면 `workboard.go`/`task_show.html`/`as.go`의 다른 단계 기호(`attachLiveWorkData`, `asInScope` 등) 때문에 그 커밋만으로는 빌드가 깨집니다. 배포 이미지 없음.

## 0단계

### 1. 담당자가 `USR-…` 로 보이던 원인

| 화면 | 표시 경로 | 판정 |
|------|-----------|------|
| 업무 수정 `wb_assignee_picker` | `PickerNames` ← `pickerNamesFor(ListAssignable)` + 선택 ID. 목록에 없으면 맵 미스 → 버튼/체크 `data-name`·요약이 ID | **A** (ID를 이름 맵에서 못 찾음) |
| 방문 조치 `mnt_assignee_multi` | 수정 전과 같이 `pickerNamesMap(ListAssignable)`만. 퇴사·타 조직·C-Level은 `ListAssignable` 밖 | **A+B** |
| 업무 조치 「주담당」 | `option`/`표시`가 `$t.Assignee`(한글 이름). ID 맵을 안 탐 | 이름으로 나옴 |

후보 C(이름과 `AssigneeUserID`가 다른 사람)는 WT-1640/1652에서 `최혜영` + `USR-178…`(hychoi)로 **같은 사람**이라 주원인 아님. 95-95/95-102 폴백은 유지.

### 2. 시간이 비어 있던 원인

수정 화면은 `$t.StartTime`/`$t.EndTime`만 읽음. 달력은 `buildBoardItem` → `expandBoardSegments` → `ListPlanSegmentsOrVirtual` / `VirtualPlanSegment` → `applySegTimes` → `ChipTime`/`StartHHMM`. 빈 시각은 달력 조회 시 `autoPlacePlanned`가 07:00부터 **DB에** 올리므로 달력만 시간이 있어 보임.

로컬 조사 당시:

| 키 | work_tasks start/end | duration_min | segments | maintenance_visits 계획·실제 |
|----|----------------------|--------------|----------|------------------------------|
| WT-1640 부여 | 빈 / 빈 | 30 | 0 | 방문 시각 빈. 달력은 자동배치 후 07:30 등으로 보임 |
| WT-1652 유구 | 빈 / 빈 | 30 | 0 | 방문 실제 빈 |

운영 실측(이전 세션): WT-1640 `08:00~08:30`, WT-1652 `10:30~11:00`, 방문 컬럼 빈. 사용자 기억 07:30 / 11:45와 **불일치** → 아래 질문.

방문 입력칸은 **실제** 시각(`maintenance_visits.start_time`). 원래 설계는 계획 시각 **자동 채움이 아님**(코드로 바꾸지 않음).

### 4. 질문 (임의 결정 안 함)

1. 운영 WT-1640/1652 시각이 달력 07:30·11:45와 DB 08:00·10:30 중 어느 쪽이 맞는지.
2. 피커 빈 계정 「이름 미등록」(95-95)과 화면 「담당자 미지정」(이번)을 병기할지.
3. 수정 화면에서 시간을 바꾸면 기존 `PushEnvelopeToVisit`이 **방문 실제 컬럼**에 계획 봉투를 씀. 「세 곳 동기화」와 「실제 자동 채움 금지」가 충돌함. 기존 함수를 재사용함(새 동기화 없음). 방문 조치 **폼**은 자동 채우지 않음.

## 수정

- `userDisplayName`: ID 이름 → 저장 이름 → 「담당자 미지정」. `USR-` 라벨 금지.
- `ensurePickerUsersNamed`: 목록 밖 담당자 임시 항목. 저장값 유지.
- 수정 시간: `planClockOf` = `CountStoredPlanSegments` + `ListPlanSegmentsOrVirtual` + `EnvelopeFromPlanSegments` + `ClockHHMM` (달력과 같은 원본).
- 빈 시각: `required` 해제, 미변경 저장 시 existing 유지.
- 구간 2개+: 읽기 전용 + 「작업 구간 N개」.
- 시간 변경 시 기존 `PushEnvelopeToVisit`·`syncVisitDateFromTask`만.
- 방문 조치: 「계획 hh:mm~hh:mm」 힌트 + 「계획 시각으로 채우기」. 입력칸은 실제 시각 그대로.
