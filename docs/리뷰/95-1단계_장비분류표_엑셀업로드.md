## 양식 파싱

파서 기준: `docs/양식/장비분류표_업로드양식.xlsx`.

- 시트 `안내`·`예시`: 무시(없어도 됨).
- 시트 `분류`·`추가항목`: 필수. 헤더 앞뒤 공백·대소문자만 허용. 다르면 **파일 전체 거부** + 기대/실제 헤더 안내.
- `분류` 헤더: 조직코드 · 분류코드 · 분류명 · 상위분류코드 · 정렬 · 사용
- `추가항목` 헤더: 조직코드 · 분류코드 · 필드키 · 항목명 · 형식 · 선택값 · 필수 · 정렬
- 키: 분류 `(조직코드, 분류코드)`, 항목 `(조직코드, 분류코드, 필드키)`. 있으면 수정, 없으면 신규. 재업로드 시 중복 INSERT 없음.
- 빈 행 건너뜀. 파일 2MB, 분류 500행, 추가항목 2,000행.
- 상위분류: 같은 조직 대분류만(파일 안 정의 허용). 2단계 초과·자기 자신·타 조직 상위는 행 오류.
- 사용 빈값=Y, 필수 빈값=N, 정렬 빈값=엑셀 행 번호. select 선택값 `|` 구분, 공백·중복 제거. select가 아니면 선택값 무시(경고).
- INSERT 조직은 **파일의 조직코드만**. `"*"` 금지. vsadmin은 활성 조직 전부, org_admin은 본인 조직만(권한 밖 행은 오류).

## 수식 주입

**업로드: 행 오류.** `=` `+` `@`로 시작하거나, 숫자 아닌 `-`로 시작하면 적용하지 않음. 정렬 `-2` 같은 정수는 허용.

**다운로드: `ExcelSafeText`로 `'` 접두.** 색상은 6자리 `RRGGBB`(`1E3A5F`). 응답은 `writeExcelFile`(Content-Length·filename*).
