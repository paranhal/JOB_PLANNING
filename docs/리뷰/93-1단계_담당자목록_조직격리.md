# 93-1단계 보고서 — 담당자 목록 조직 격리 (D-104)

기준: `커서_작업지시서_93-1_담당자목록_조직격리.md`

## 한 줄

담당자 목록·저장이 현재 조직을 따르고, 미등록 이름은 회색 칩으로만 남긴다.

## 동작

- `UserRepo.ListAssignable(orgID)` / `FindAssignable(orgID, idOrName)` — 빈 조직 거부. `OrgAll`만 전 조직. 도서관(O01)은 예전 빈 `org_id` 계정도 포함한다.
- 화면 드롭다운은 `listAssignableForPicker`. 비젼관리자 「전 조직」에서는 목록을 비우고 담당자 select를 숨긴다.
- 저장 시 타 조직·신규 미등록 이름은 400 `"같은 조직의 담당자만 지정할 수 있습니다"`. 기존 미등록 문자열은 그대로 허용.
- 일일 업무 등록 범례·열: 미등록이면 회색 + 툴팁 「사용자 미등록」.

예외(담당자 선택 아님, `OrgAll` 조회): 서명 파일(`signature.go`), 알림 수신자 조회(`assign_notice.resolveUser`), AS 가져오기 알림(`as_pull`). 87단계 협조 수신자 코드는 아직 없음.
