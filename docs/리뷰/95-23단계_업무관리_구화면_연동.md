# 95-23 업무 관리(새 화면) ↔ 구 화면 연동

작성: 2026-10-24 · D-164/D-165. VERSION `95-23`. 마이그레이션 없음. 운영 배포 안 함.

## 1. 한 줄

`/workboard/board` 가 구 화면(`/workboard/register`, `/work`, `/work/all`)과 **같은 수집 함수**를 쓰도록 맞춘다. 새 SQL을 만들지 않고 `autoPlacePlanned`·팔레트·미날짜 AS·지연 버킷·범위 규칙을 재사용한다. 오른쪽 「미배치 업무」 박스는 `docs/양식/업무관리-미배치박스-시뮬레이션.html` 기준이다.

## 2. 원인 6항 대응

읽기 화면에서 데이터를 바꾸는 호출은 `autoPlacePlanned` 하나뿐이다.
