# 95-36단계 — 조직관리자·지원 대리 입력, 담당자 필수, 시점 보기 끄기

기준: `커서_작업지시서_95-36_조직관리자_지원_대리입력_권한정리.md`  
선행: 95-35. 실행일: 2026-10-25. 배포 이미지 없음.

## 한 줄

조직관리자와 지원은 자기 조직 업무를 대신 입력할 수 있다. 담당자는 반드시 실제 담당이고, 입력자는 대체 입력으로만 남는다. 시점 보기(`VIEW_AS_ENABLED`)는 기본 꺼짐.

## 권한 매트릭스 (헬퍼 기준, 자기 조직)

`canEditASReceipt` / `canModifyAS`(완료) / `canEditVisitDate` / `canEditTask` / `canEditSalesActivity`. 완료 AS는 소유자면 unlock 없이 가능, vision_admin은 unlock 필요. 조직 경계는 핸들러 404/403.

| 역할 | AS 접수(타인) | 완료 AS(타인) | 방문일(타인) | 업무·완료 업무 | 영업 활동(타인 작성) |
|------|:---:|:---:|:---:|:---:|:---:|
| vision_admin | O | X (unlock) | O | O | O |
| org_admin 홈 | O | O | O | O | O |
| support 홈 | O | O | O | O | O |
| tech 본인 | O | O | O | O | O(본인 작성명) |
| tech 타인 | X | X | X | X | X |
| sales 타인 | X | X | X | X | X |
| sales 본인 활동 | — | — | — | — | O |
| c_level | X | X | X | X | X |
| observer(읽기전용 org_admin) | X | X | X | X | X |

담당자 없는 AS: `sessionOwnsAS` 는 support만 true, org_admin은 false.

## 구현 요지

- §3-1 `canActForOthers`: vision_admin, 홈조직 org_admin, 자기 조직 support. 읽기전용·시점 보기 중이면 false. AS 접수/완료/방문일 수정이 이 헬퍼를 씀.
- §3-2 조치 `Worker` = AS 담당자. 로그인 이름 폴백 제거. 지원만 빈 담당자를 본인으로 채움. 조직관리자 이름은 자동 담당자로 안 넣음(선택기에서 고르면 허용).
- §3-3 AS 조치 `OnBehalf` 유지. 업무·영업활동·점검방문에 `acted_by_*` / `on_behalf` 열(마이그레이션 085, InitDB 멱등). 표시 `홍길동 (대체 입력: 김팀장)` (`OnBehalfLabel` / `ActorLabel`).
- §3-4 org_admin·support 저장 시 담당자 필수. 서버 `assignee_required` + `focus=assignee`. 클라이언트 `data-require-assignee` / `data-focus-target="assignee"`. 95-32 연결 팝업은 그대로 optional. 영업 활동은 담당 필드가 없어 필수 검증 없음.
- §3-5 완료 AS·완료 업무를 org_admin·support가 수정. 영업 사업 단계 규칙(95-2G)은 유지.
- §3-6 `VIEW_AS_ENABLED` 기본 false. POST `/view-as` 404, 쿠키 삭제, UI 숨김. 기존 view-as 테스트는 `enableViewAsForTest`로 켠다.
