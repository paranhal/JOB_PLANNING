# 95-106 — 조치 처리담당자가 아이디로 보임

작성: 2026-11-04. 운영 배포 대상.

## 원인

처리담당자 선택기는 사용자 ID(`USR-…`)를 고르고, 이름이 비거나 ID와 같으면 버튼·저장값에 아이디를 그대로 썼다.

## 수정

- 표시·저장 모두 `full_name` → `username` 순으로 이름을 쓰고, `USR-` 는 쓰지 않는다.
- 이미 `assigned_to` 가 아이디로 저장된 건은 조치 화면에서 이름으로 풀어 보여 주고, 저장 시 이름으로 고친다.
