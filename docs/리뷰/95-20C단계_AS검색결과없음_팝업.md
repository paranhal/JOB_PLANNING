# 95-20C AS 조치 검색 결과 없음 팝업

선행: 95-20A (`7356654`). VERSION `95-20C`. 마이그레이션 없음. 운영 배포 안 함.

## 1. 원인

업무 관리 `+ 업무 등록` → AS 조치에서 AS 접수번호를 검색해도 안내가 없었다.

95-7 조회 스크립트 `window.bindASRegisterLookup`이 `workboard/_modals.html`(예전 `/workboard/register` 전용)에만 있었다. 업무 관리 화면은 이 파일을 include하지 않아 `_new_work_modal.html`의 `if (window.bindASRegisterLookup)`가 건너뛰어지고 `/workboard/as-lookup`이 호출되지 않았다. 95-20A 누락이다.

## 2. 한 줄

조회 스크립트를 `server/web/static/js/as-register-lookup.js`로 한 곳만 두고, 업무 관리 모달에서는 `kind=missing`일 때 `role=alertdialog`로 접수 추가/닫기를 띄운다. 예전 화면은 `[추가][확인]` 그대로다.

## 3. 변경 파일

- `server/web/static/js/as-register-lookup.js` — 공용 조회. `missingDialog: true`일 때만 팝업(700ms/Enter, Esc 닫기, 검색어 텍스트 노드, `can_create`, `new_href` 새 탭, focus 재조회)
- `server/web/templates/workboard/_modals.html` · `_new_work_modal.html` — `<script src="/static/js/as-register-lookup.js">`. 새 모달은 조각 주입 직후 `bindASRegisterLookup({ missingDialog: true })`
- `server/web/templates/workboard/_new_work_modal.html` — 팝업이 열려 있으면 바깥 Esc로 모달을 닫지 않음
- `server/internal/handler/workboard_as_lookup_20c_test.go` — 지시서 4장 9항
- `tailwind.config.js` content에 `./web/static/js/**/*.js` (커밋 ②)
- `VERSION` · `server/VERSION` → `95-20C` (커밋 ②)
- `server/web/static/vendor/tailwind.css` — 커밋 ②에서 `npm run build:css`
- 이 보고서 · `docs/리뷰/screenshots/95-20C/`

`/workboard/as-lookup` JSON은 바꾸지 않았다. 95-7 `workboard_as_lookup_http_test.go` 미수정.
