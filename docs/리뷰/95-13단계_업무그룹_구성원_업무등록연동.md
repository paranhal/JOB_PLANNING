## 구현

### 팝업 제자리 (fetch)

- `X-Requested-With: fetch` + `Accept: text/html` POST → 200 `_form.html` 조각. 그 외는 기존 303.
- 구성원: 체크박스 + 이름 검색 + 「선택한 구성원 추가」. `member_ids[]` 일괄.
- 이미 소속·`ux_wgm_active_member` → 오류가 아니라 안내.
- 구성원 행에 「그룹장으로 지정」·「제거」. 닫을 때 `location.reload()`.
- `MembersOn` 이 `left_on>=오늘` 을 포함하므로, 제거 직후 조각에서는 `LeftOn` 이 있는 행을 빼서 표에 안 남긴다.

### 새 그룹

- 기간·구성원 체크박스·그룹장(선택된 구성원). `CreateWithMembers` 한 트랜잭션(`nextSeqTx`). 그룹장이 구성원 밖이면 롤백.
- fetch 생성 성공 시 상세 조각으로 전환.

### 일일 업무

- 마이그레이션 **081**: `work_tasks.work_group_id TEXT NULL`, `ix_work_tasks_group`. FK·시드 없음. `.down.sql` 은 인덱스만 제거(SQLite 컬럼 DROP 불안정).
- 후보: 같은 조직 활성·기간 내. 조직관리자·비전관리자=조직 전체, 조직원=본인 소속.
- 그룹 선택 시(클라이언트) 주담당=그룹장, 참여자=나머지. 저장 시 `assignee_source=manual`. 구성원 변경은 소급하지 않음. 「그룹 구성원으로 다시 채우기」만 갱신.
- 타 조직 그룹 → 95-12 오류 팝업. 종료·기간 지난 그룹 거부.
- 카드·칸반·목록·상세·작업 조치에 「그룹: ○○」 칩. 등록 화면 필터.
