# 95-215 구현 보고 — 조직 밖 담당자 표시·복사 재발 방지 (규칙 O)

작성 2026-11-17 · 브랜치 `works`(커밋만, 푸시·배포 안 함) · 운영 DB 접근·수정 없음

## 요약 (배포 판단용)
- **규칙 O**: 한 조직 화면의 담당자는 그 조직 소속 직원뿐. 판정은 공통 함수 한 곳(`repository/assignee_org_rule.go`)을 쓴다.
- **막는 쪽(정기점검)**: 전년·올해 상속, 사이트·지역 기본 담당, 업무 그룹 리더·구성원 복사는 **그 사이트 조직 소속일 때만**. 아니면 담당 없음. 업무 그룹 구성원 면제 제거. 일괄 배정·월 대상·방문 폼의 직접 입력은 **다른 조직 직원**이면 거부.
- **읽는 쪽(표시)**: 미완료 카드의 담당이 다른 조직 직원이면 이름을 감추고 「담당 재배정 필요」. 카드는 남는다. **완료·취소는 이름 그대로**(실적 이력). 저장 데이터는 바꾸지 않는다(일괄 UPDATE 없음).
- **게이트**: `make test-gate` 통과 2652 / 실패 7 (기존 7 · **신규 0** · 해결 0). 이 7건은 이전부터 알려진 실패다. ui_lint 통과. 실제 브라우저 1440/820/390 통과.
- **하지 않은 것(지시)**: 도서관 「조직 빈 사용자 허용」 제거, `prev`(같은 이름 통과) 축소 — 별도 지시서. 상수 `assigneeLibraryEmptyOrgAllowed` 한 곳만 바꾸면 된다.

## 4. 알아 둘 점
- **그룹**: 타 조직 구성원이 든 그룹은 DB 제약(`member org mismatch`)이 이미 막는다. 코드 쪽 방어는 옛 데이터 대비로 유지했고 시험은 제약 때문에 재현 불가임을 기록한다.
- **사용자 미등록 이름**: 상속에서는 제외(조직을 확인할 수 없어서). 직접 입력은 종전대로 저장하고 「사용자 미등록」 표시를 유지한다.
- **1초 캐시**: 점검 화면이 한 요청에서 직원·사이트 조직을 여러 번 읽어 쿼리 상한(60)을 넘겨서, 직원·사이트 조직 목록을 1초 동안만 재사용한다(조직 변경은 1초 안에 반영).
- **도서관 「조직 빈 사용자」**: 박노선의 조직이 비어 있으면 도서관 소속으로 판정돼 이번 규칙으로도 안 걸린다. 운영 SQL ①·⑤ 결과와 별도 지시서가 필요하다.
- **미확인**: 주간 보고서 담당 표시, 정기점검 달력 카드의 별도 시험(마스킹 코드는 있으나 달력 전용 시험은 없음).
