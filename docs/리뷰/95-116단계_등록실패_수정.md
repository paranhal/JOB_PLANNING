## (c) UI 막대 방식

`w-[n%]` 런타임 클래스는 빌드 CSS에 없다. 비율은 `ExecBarPct`로 0–100 연속값. 기존 `task_show.html` 막대는 `style="width: N%"`인데 **baseline에 이미 있는 파일**이라 신규 `_org_cards.html`(위반 0이어야 함)에 복사할 수 없다.

선택한 방식: **SVG `viewBox="0 0 100 1"` + `rect width`/`x` 속성.** `style=` 없음. `BarDone` 등 기존 퍼센트 필드를 쓴다.

토큰: `_multi_timeline` `bg-info-soft`, `_work_period_dates` `text-danger`. DOM id 호스트 3개.

`as/action.html`은 이미 baseline보다 raw_color가 적다(113D). baseline을 안 바꾸므로 감소는 실패가 아니라 로그만 남기게 `TestUILintRatchet`를 맞췄다. 증가는 그대로 실패.
