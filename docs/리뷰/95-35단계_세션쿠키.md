# 95-35단계 — 로그인 쿠키를 세션 쿠키로

기준: `커서_작업지시서_95-35_로그인_브라우저종료시_로그아웃.md`  
선행: 95-34. 실행일: 2026-10-25. 배포 이미지 없음.

## 한 줄

로그인 `token` 쿠키에서 `Max-Age=86400`을 빼 브라우저를 닫으면 로그아웃되게 한다. JWT `exp` 24시간·사용 중 `refreshSession` 연장은 그대로다.

## 변경

`writeSessionCookie` 한 곳만 `tokenCookie(tokenStr, 0)`으로 바꿨다. 로그인, `refreshSession`, 조직 전환, 재검증이 모두 이 함수를 쓴다. 삭제용 `tokenCookie("", -1)`(로그아웃·비활성)은 유지. `COOKIE_SECURE`·HttpOnly·SameSite=Lax·Path=/ 는 그대로. `jp_flash_err` 등 다른 쿠키는 건드리지 않음. 로그인 화면 문구도 그대로.

## 쿠키 헤더 전/후

값은 보고서에 적지 않는다.

| | Set-Cookie |
|--|-----------|
| 전 | `token=…; Path=/; Max-Age=86400; HttpOnly; SameSite=Lax` |
| 후 | `token=…; Path=/; HttpOnly; SameSite=Lax` |
| 로그아웃·비활성 | `token=; Path=/; Max-Age=0; HttpOnly; SameSite=Lax` (+ Go가 붙이는 과거 `Expires`) |

## §5 Chrome 세션 복원

Chrome「이전 세션 열기」가 켜져 있으면 브라우저를 닫아도 세션 쿠키가 복원될 수 있다. 서버에서 막을 수 없고, 완전한 로그아웃은 「로그아웃」 버튼이다. 무활동 로그아웃은 95-35A.
