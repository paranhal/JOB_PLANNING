# 95-104 — AS 조치 키워드 직접 입력 시 후보 체크 유지

작성: 2026-11-03. 지시서 `커서_작업지시서_95-104_긴급_AS조치_키워드_수동입력시_후보_체크_사라짐.md`.

## 0단계 (수정 전 재현)

`server/web/templates/as/action.html` 에 스크립트가 **둘** 있었다.

| 스크립트 | `#as-kw-list` | 체크 보존 | 직접 입력 |
|----------|---------------|-----------|-----------|
| `bindKw()` (~961) | `innerHTML` 다시 그림 | `keep` 있음 | `as-action-taken` 입력만 fetch |
| `bindKw95_85()` (~1176) | `innerHTML` 통째 덮음 | **없음** (`checked` 미생성) | **`as-kw-manual` 입력마다 `run()`** + **로드 직후 `run()`** |

둘 다 같은 `getElementById('as-kw-list')` 를 갱신한다. 95-85 쪽이 나중에 실행되고, 로드 직후 `run()` → `/as/keywords/suggest` → `list.innerHTML = html` 이라 서버가 `{{if .Linked}}checked{{end}}` 로 내려준 연결 키워드가 지워진다. 직접 입력 한 글자도 같은 `run()` 이라 사용자가 체크한 후보·`#as-kw-new` 도 사라진다. `texts()` 에 직접 입력 칸은 없어 재조회는 후보와 무관하다.

`as/form.html` 은 옛 `bindKw()`만 있고 `keep` 이 있다. `as-kw-manual` 을 입력해도 fetch 를 부르지 않는다. 이번 증상은 **조치 화면 한정**.

## 구현

- `bindKw` / `bindKw95_85` 인라인 제거. `as_keywords.js` 한 곳.
- 다시 그리기 전 `#as-kw-list`·`#as-kw-new` 체크를 `keep` 하고 복원. 응답에 없어도 파란 테두리로 유지.
- `as-kw-manual` 은 `renderChosen` 만. 조치내용·원인만 debounce 400ms 재조회.
- 같은 후보 집합이면 DOM 재작성 없음 (`kw_suggested` 유지).
- 필드명 `kw_*` / `kw_suggested_*` / `kw_manual` 변경 없음.
