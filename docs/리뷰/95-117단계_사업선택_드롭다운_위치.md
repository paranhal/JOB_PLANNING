## 원인

`.combobox-list` 가 `position:absolute` 인데 피커 루트 `.pp` 에 `relative` 가 없어 containing block 이 뷰포트가 됨. 입력칸 클릭 시 목록이 모달 안이 아니라 페이지 하단·전체 폭으로 그려짐. 목록 데이터·필터·「타 부서 사업 보기」(흐름 배치)는 원래부터 정상.

## 수정

- `.pp { position:relative }`
- `.pp .combobox-list { position:static; width:100% }` — 타 부서 목록과 같이 입력칸 아래 흐름. 모달 `overflow` 에 잘리지 않음. `max-height:15rem` + 내부 스크롤.
- 입력칸+목록을 `relative` 래퍼로 묶음. 열릴 때 `scrollIntoView({block:nearest})`.
- 95-113(내 부서 우선, 타 부서는 버튼만, 403, 사업 필수 아님) 로직 미변경.
