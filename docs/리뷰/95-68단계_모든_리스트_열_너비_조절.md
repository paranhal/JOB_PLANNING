# 95-68단계 — 모든 리스트 열 너비 조절

기준: `claude/커서_작업지시서_95-68_모든_리스트_열_너비_조절_공통.md` (저장소에 없음, 채팅 요점). 실행일: 2026-10-29. 선행: 95-67.

`table-cols.js`를 화면별 하드코딩에서 **자동 초기화**로 바꿨다. 표는 `width:100%`가 아니라 **열 폭 합(px)**. 핸들은 항상 보이는 얇은 구분선 + 넓은 클릭 영역. 저장키 `table_cols:*` 호환(projects / contracts / product_groups). 일일 업무 `board_list.html`은 CSS grid 변수.

조사 대상: `<table>`+`<th>`/`<thead>` 또는 `wl-head` 가 있는 템플릿 **94개**.
