## 변경 요지

- 마이그레이션 103: `work_tasks.est_minutes`·`next_action_date`·`completion_condition`, 구간 이동·출처 열, 이탈 `force_reason`, 부분 UNIQUE `ux_wts_open_per_worker`.
- LiveAdapter: 행정/지원·작업 `Enabled=true`. AS·정기점검·영업은 시작 버튼·`/live/start` 거부. 끼워넣기 피해는 비활성 유형도 허용.
- 끼어드는 업무: 보드/상세에서 `_new_work_modal.html` 을 열고 `live_host_id` 를 붙여 `CreateTask` → `applyPendingInterrupt` → `applyLiveInterrupt`. HTTP `POST …/live/interrupt` 도 같은 엔진. 담당자 초기값은 `defaultAssigneeSeed`.
- 시간 진척 분모는 `est_minutes`(완료 회차만). `duration_min` 시계 외피는 쓰지 않음.
- 긴급 배너: 자동으로 진행 중 구간을 닫지 않음.

## 지시와 다른 점

- T26은 플레이라이트 환경이 없어 Skip. 로컬에서 수동 확인.
- T27은 작업자당 열린 실제 1건 제약 때문에 조합마다 이전 열린 구간을 닫고 다음 호스트를 심는다. 엔진은 끼워넣기 시 그 작업자의 열린 실제를 모두 닫는다.
- 끼워넣기 전용 얇은 모달(`live-interrupt-modal`)은 T18·상세 폴백용으로 남겼다. 보드·상세 Alpine이 있으면 `_new_work_modal` 을 연다.
- `cmd/server/main.go` 에 live POST 라우트를 붙였다. 테스트는 `mountLiveWorkRoutes`.
- B/C/D 실시간 시작·원본 화면 완료 연동은 하지 않음.
