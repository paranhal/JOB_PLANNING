## 0. 원인 확정

재현 테스트 `TestMnt95_15ARegionPageShowsUnspecified`: 지역 빈 사이트 3곳 + `충남` 1곳 → 구현 전 `RegionAssignees` 가 `strings.TrimSpace(cfg.Region)==""` 이면 `continue` 하여 **충남 1곳만** 보이고 「지역 미지정」이 없었다. 실패로 고정한 뒤 통과.

일괄 등록은 고객 주소에서 `ExtractKoreaRegion` 만 채운다. 주소가 없거나 시·군만 있으면 지역이 빈 값으로 들어가고, 위 `continue` 때문에 지역별 담당 화면에서 사라졌다. 등록 안내도 「목록에서 확인」 수준이라 확인 경로가 없었다. 지역이 비면 95-14 지역 기본 담당도 적용되지 않는다.

## 4. 미배정 목록

`ListOpenUnassignedSlots` / `ListUnassignedMonthSlots` 는 지역으로 사이트를 버리지 않는다. `annotateUnassignedRegion` 은 빈 지역일 때 지역 담당 칩만 건너뛴다.  
`TestMnt95_15AUnassignedKeepsEmptyRegion`: 지역 없는 월 사이트가 8월 미배정에 **포함**. **누락 없음.** 별도 「지역 없음」 그룹은 넣지 않았다.

사이트 예외 담당은 `site_form.html` 에 그대로 있다. 지역 없는 사이트는 예외 담당으로만 배정 가능하다.

## 동작

- 지역별 담당: 요약 「전체 N · 지정 M · 미지정 K」, 미지정 K>0 이면 맨 위 「지역 미지정 · 사이트 K곳」(담당 입력 없음) + 「지역 지정하러 가기」(`?region=none`).
- 점검 사이트 목록: 지역(전체/값/지역 없음)·주기·이름·`?batch=`·최근 등록순. 체크 + 지역 일괄 지정(콤보·직접 입력, 공백만 정리, `ExtractKoreaRegion` 강제 변환 없음). 타 조직·없는 ID 건너뜀, 3,000 초과 400, 같은 값 재제출 변경 0. 방문 소급 없음. 「주소로 지역 채우기」는 빈 지역만, 고객 주소 불변.
- 일괄 등록: 미리보기 「지역을 알 수 없는 학교 N곳」. 선택 입력 「지역을 지정하는 값」은 **주소로 비는 행에만**. 결과: 지역 없음 N곳, `?batch=`, 지역 없음이면 `region=none` 링크, 점검 계획 링크. 일정 자동 생성 없음.
- 스키마: `maintenance_site_config.bulk_batch_id` (`083`, 시드 없음). `AppSchemaVersion` 72 유지(082와 동일 방식).
