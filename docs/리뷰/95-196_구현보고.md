## 1. 재현 (수정 전)
하위 기관이 있는 고객의 사업(사이트 0건)에서 사업 상세 「사이트·진행」은 한 줄 문구(「등록된 사이트가 없습니다」)와 작은 버튼뿐이었고, 사이트 등록 화면은 항상 학교 탭으로 열렸다. 새 시험은 이 동작(빈 상태 카드·하위 기관 버튼·카드·기본 탭)을 요구해 수정 전에는 컴파일·단언에서 실패한다.

## 2. 변경 (DB 스키마·마이그레이션 변경 없음)
### 4-1 사업 상세 「사이트·진행」(project/show.html, handler/project.go)
- 제목 줄 오른쪽에 `btn btn-primary btn-sm` 「사이트 등록」(`data-site-progress-reg-btn`), 권한(`canRegisterProjectSites`)이 없으면 숨김.
- 사이트 0건: 한 줄 문구 대신 **빈 상태 카드**(`data-site-empty-card`) — 「이 사업에 등록된 사이트가 없습니다. 사이트를 등록해야 정기점검·AS·작업에서 대상 사이트를 불러올 수 있습니다.」 + 큰 버튼 「사이트 등록하기」(`data-project-sites-link`). 권한이 없으면 버튼 대신 안내(`data-site-register-denied`).
- 이 사업 고객에 **미등록 하위 기관이 1곳 이상**이면 「고객 하위 기관 N곳 등록」(`data-site-children-btn`, `…/sites#children`). N 은 활성 customer 중 이 사업에 아직 없는 곳(3단계 재귀, 쿼리 1개).
- 「등록 N곳 중 작업 연결 M곳」은 0건일 때 숨김. 사이트가 있으면 하단에 「사이트 등록」(+하위 기관 보조 버튼). 헤더 버튼(26행)은 유지.
### 4-2 사이트 등록 화면 「고객 하위 기관」 카드(project/sites.html, `site_children.js`, handler)
- 사업 고객(`customer_id`, 없으면 `ordering_party_id`)에 하위 기관이 있을 때만 보이는 카드(`data-site-children-card`, `#children` 로 열리면 스크롤): 「{고객명}의 하위 기관 N곳 (미등록 M곳)」, 업종별 건수 칩(업종 없음은 「(분류 없음)」), 목록(이름·업종·시도·시군구, 등록된 곳은 비활성+「등록됨」), 「미등록 전체 선택」·「선택 해제」, 「선택 등록 (N)」.
- **인라인 확인 단계**(브라우저 `confirm()` 없음): 「등록 N곳 · 이미 등록 M곳은 건너뜁니다」 + [등록 확정]/[취소]. 확정하면 **기존 `POST …/sites/add-schools`(`SitesAddSchools`)를 그대로** 호출한다(`AddSitesFromCustomers`: 활성·중복·이름 충돌·2,000곳 상한·`skippedItems`). 새 저장 로직 없음.
- 새 라우트 `GET /projects/:id/sites/children`(`SitesChildren`, 조회 권한 `canViewProjectEquip`). 후보 `ListChildCustomers`(repository `project_site_children.go`): 최대 3단계 재귀 CTE, 활성·`party_kind='customer'`, 조직 필터 없음(95-167), 이미 등록은 `Registered=true`.
- 권한이 없으면 카드는 보이되 버튼 비활성+안내. 기존 유형 탭·시도 필터·엑셀 일괄·검색 등록은 바꾸지 않았다.
### 4-3 기본 유형 탭
- `DefaultSiteType(projectID)`(repository): 쿼리 `type` 이 명시되면 그것이 최우선(`Sites` 핸들러), 없으면 ① 이 사업의 기존 사이트 고객 업종 최다 → ② 사업 고객 하위 기관 업종 최다 → ③ `school`. 업종 매핑은 기존 `siteTypeOfIndustry`(학교→school, 공공기관→public, 도서관→library, 그 외 private) 재사용, 업종이 비면 판정에서 제외, 동수면 school→public→library→private. `normalizeProjectSiteType` 의 default(`school`)는 그대로(잘못된 값 방어).
