# 95-45단계 — 분기·반기·연 점검을 월 단위·지역/사이트별로 등록

기준: `커서_작업지시서_95-45_정기점검_기간주기_월단위_지역사이트_등록_업무등록_점검접수추가.md`  
선행: 95-14·15·16A·18·43. 실행일: 2026-10-25.  
운영·개발 DB를 코드로 바꾸지 않음. `server/data` 미커밋. 배포 이미지는 요청 시에만.

## 원인

`InspectionCycleDue` 는 반기를 1·7월만, 분기를 1·4·7·10월만 대상 달로 본다. 대기 슬롯(`computeOpenUnassignedSlots`)은 기간 주기 사이트를 **기간 마지막 달**에만 「미확정」으로 올린다. SI처럼 사이트가 많은 팀은 상반기 중 원하는 달에 지역·사이트를 정해 올릴 방법이 없었다.

## 슬롯 계산 전후

| 조건 | 수정 전 | 수정 후 |
|------|---------|---------|
| 반기 사이트, 2월, target 없음 | 목록에 없음 | 없음(마지막 달 미확정만, 6월) |
| 반기 사이트, 2월, 2월 target | 없음 | 대기 「2월 등록」 |
| 같은 건 3월, 방문 없음 | 없음 | 이월 「2월 등록 · 미배정」 |
| 방문 생성 후 그 달 | (해당 없음) | 목록에서 사라짐 |
| 6월, target/방문/skip 없음 | 미확정 | 미확정(유지) |
| 6월, target 또는 방문 있음 | 미확정일 수 있음 | 미확정 아님 |
| 월·격월 | 기존 | 기존과 동일 |

## 동작

- 테이블 `maintenance_month_targets`(마이그레이션 089, InitDB V89 멱등). 활성 UNIQUE(plan, customer, slot, year, month, round). `org_id` 필수(95-43).
- 기간 주기만 등록. 한 기간에 `SiteRounds()`×슬롯을 넘기지 않음. 같은 달 중복 거부. 월·격월은 거부.
- 계획 관리 `/maintenance/:id/manage` 「월 점검 대상 등록」: 월 선택, 지역 체크(지역 미지정 포함), 사이트 검색, 결과 문구. 권한 `canEditMaintenanceSchedule`. 방문이 있으면 취소·월 이동 거부.
- 업무 등록 모달: 점검 목록 아래 「정기점검 등록」. 간이 폼 → 연도 계획 자동 생성 → month target(+방문) → 목록 자동 선택. AS는 빈 목록에도 「AS 접수 추가」.
- 캐시 무효화. 대기 계산에 target 1회 조회. SI 300곳 시나리오 쿼리 ≤30.
