## 동작

- `inspection_products`(조직별 마스터) + `site_inspection_products`(사이트 연결). `has_klas`/`has_rfid` 컬럼은 유지.
- O01 마스터가 비어 있으면 **레거시**: 기존 KLAS·앤로보틱스 슬롯 그대로. 「기본 제품 가져오기」는 도서관 화면에서만, 클릭 시에만 이관(자동 실행 없음).
- O02·O03는 처음부터 신 모드. 마스터가 비어 있으면 generic 1건. KLAS/RFID 문자열은 매칭하지 않음.
- 슬롯 키는 신 모드에서 `product.code`, 표시명은 `product.name`. 방문 `product_type`은 표시명 문자열 유지.
- 화면: `/maintenance/products`. 사이트 목록은 점검제품 칩. 사이트 폼은 조직 제품 체크(레거시 O01만 KLAS/RFID 체크).
- 사이트 목록·엑셀·자동배정은 현재 조직(계획 `org_id`)으로 걸러 도서관 사이트가 SI 계획에 섞이지 않게 함. 빈 `org_id` 사이트는 도서관 계획에만 붙임.
- C-Level: 제품 화면 GET 허용, POST 403. 타 조직 `product_id` 연결 400, 타 조직 제품 URL 404.
- 95-4 엑셀 매칭은 다음 단계. 이번 단계에서는 사이트 엑셀 열을 `점검제품`으로 바꿈.
