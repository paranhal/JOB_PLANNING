# 95-93 핫픽스 — 사이드바 Alpine 속성이 글자로 보이던 문제

작성: 2026-11-03. 운영에 올라간 이미지는 아직 **95-92**. 로컬 `:8080`과 `deploy/server-app.tar`만 95-93으로 다시 만들었다. 운영 컨테이너는 교체하지 않았다. 2026-11-03 16:13에 로컬에서 메뉴 접힘·펼침과 버전 표시를 다시 확인했다.

## 원인

95-93 UI 린트에서 `_nav_tree.html` 2번째 줄의 `style="-webkit-overflow-scrolling:touch"`를 빼면서 **`>`를 그 줄에서 닫았다.**  
그 다음 두 줄(`x-data="navMenu(...)"`, `@click=...`)이 `<nav>` 속성이 아니라 본문 글자가 되어, 메뉴 그룹이 접히지 않았다.

## 수정

HEAD와 같이 2번째 줄은 `text-sm" style="-webkit-overflow-scrolling:touch"`로 두고, `>`는 `@click` 줄 끝에서만 닫는다.

UI 린트는 `-webkit-overflow-scrolling:touch`만 있는 `style=`은 InlineStyle 집계에서 빼서, 이 필수 속성을 다시 넣어도 래칫이 깨지지 않게 했다.
