# 95-86 긴급 — 일 보기 바·손잡이가 안 움직이던 이유

작성: 2026-11-04.

## 0단계 — 테스트는 통과했는데 실제 화면은 안 된 이유

`Test95_86_DesktopMouse` / `95_86_desktop_mouse_browser.mjs` 는 httptest에 `/static`을 붙이고 **실제 `base.html`로 렌더한** `/workboard/board?view=day` 를 Playwright로 연다. **스크립트를 따로 주입하지는 않는다.**

그런데도 운영 화면과 어긋난 이유:

1. **Go 렌더 테스트**(`Test95_86_DayBarRenderSnapshot` 등)는 HTML 문자열만 본다. JS가 `#board-root`에 이벤트를 다는지는 검사하지 않는다.
2. Playwright는 `waitUntil: 'domcontentloaded'` 와 `[data-board-bar]` 만 기다렸다. 바 DOM이 있으면 통과 조건에 들어가고, **`board_schedule.js`가 `if (!root) return` 으로 끝난 뒤인지**는 표시가 없었다.
3. Playwright가 없는 환경에서는 `Executable doesn't exist` 로 **Skip** 된다. 이 경우 마우스 검증은 한 번도 안 돈다.
4. `board_schedule.js` 가 `<head>` 에 **defer 없이** 있어, 파싱 시점에 `#board-root` 가 없다. 첫 줄에서 return 하면 손잡이·바 pointer 핸들러가 없다. CSS(b1c535f)만 반영된 상태가 된다.

재현: 같은 파일을 head에 두면 무반응, 본문 끝에 두면 정상.

## 수정

1. `base.html` head 의 `/static/js/*` 전부 `defer`. `board_schedule.js` / `board_kanban.js` 는 `DOMContentLoaded`(또는 이미 완료면 즉시) 래핑도 유지. 초기화 후 `data-board-sched-bound` / `data-kanban-bound`.
2. 바 ±15 (`data-nudge`) 버튼·클릭 핸들러 삭제. 종료 시각은 손잡이만.
3. 일 보기 pointer 드래그: 버튼·손잡이 제외 바 어디든. `elementFromPoint`로 담당자 열(`data-dayzone`) 변경. 주·월은 기존 HTML5 DnD.

- `Test95_86_HeadScriptsDeferOrReady` — head 스크립트 defer/ready, ±15 없음
