기준: `커서_작업지시서_95-2_사업계약_엑셀업로드.md`  
실행일: 2026-10-20. 운영·개발 DB(`server/data/app.db`) 미변경. `server/data` 미커밋. push 없음.

게이트 답(사용자): 용역·구매는 기존 5종에 접음. 담당은 `sales`/`execution`. VAT는 포함 금액+플래그만. `AppSchemaVersion` 72는 그대로. C-Level 장비 분류는 URL만. 점검 제품 시드 없음.

2026-10-21 지시서 갱신: 샘플은 `docs/양식/사업등록_업로드_최종_47건.xlsx`(47건·오류 0). 날짜는 날짜 셀(일련번호·`MM-DD-YY`)과 글자 `YYYY.MM.DD` 둘 다. 계약방식은 끝의 「계약」을 떼고 비교(`수의계약`=`수의`). 추가 계약은 다른 이름의 별건. 담당자 불일치는 오류가 아니라 경고+빈칸.

## 매핑

계약 = `work_projects`. 별도 contracts 표 없음.

| 양식 | 저장 |
|------|------|
| 사업명 | `work_projects.name` |
| 부서 | `org_id` (도서관사업팀→O01, SI/미디어는 `orgs` 이름 조회. `*` 금지) |
| 발주처 | `ordering_party_id` + `ordering_party` (고객 마스터 이름 일치, 없으면 행 오류) |
| 최종수요처 | `contract_end_customers` (`;` 또는 `,` 구분) |
| 사업유형 | 공사→`construction`, 구축→`build`, 용역·개발→`dev`, 유지보수→`maintenance`, 구매·기타→`other`. 빈 칸은 이름 키워드(공사/구축/용역/구매·구입/유지보수) 후 남으면 `other` |
| 거래구분 | `direction` `revenue`/`cost`. 빈값=매출. 대시보드 KPI는 매입 제외 |
| 기간 | `start_date`/`end_date`. 날짜 셀 일련번호·표시값·글자 `YYYY.MM.DD`/`YYYY-MM-DD`. 없는 날짜(2월 30일)는 오류 |
| 계약방식 | 끝 「계약」 제거 후 `수의|입찰|제안입찰|농공단지수의|민간계약|기타`. 빈칸 허용 |
| 금액 | `contract_amount` + `amount_vat_included=1`. 공급가·세액 컬럼 없음 |
| 계약번호 | `contract_no` (있으면 중복 키) |
| 계약담당·업무담당 | `project_assignments` duty `sales` / `execution`. 비우면 됨 |
| 상태 | 양식에 없음. `status=active`. 화면 기간 계산 |
| 영업 | `sales_project_id` 비움 |
| 연차 | `contract_years`. 1년 이하면 만들지 않음. 12개월, 말일 보정, 마지막 31일 이하 합침, 금액은 일수 비례·마지막 나머지 |

헤더는 양식 그대로 `사업명 *` … `비고` 14열 일치. 뒤 참고열은 허용. 시트 `계약`만 읽음.

한도: 파일 2MB, 데이터 500행. 미리보기 무쓰기, 적용 시 오류 행 건너뜀. 중복(계약번호 또는 사업명+발주처+시작일+금액)은 건너뜀.
