# 88단계 보고서 — 서명 없으면 이름 (D-94)

기준: `커서_작업지시서_88단계_서명없으면_이름.md`, D-94.

## 한 줄

서명 PNG가 없거나 읽을 수 없으면 **성명**을 서명 칸에 넣고, 결재 전 칸·검토란은 비운다. 판정은 `model.SignatureOrName` 한곳.

## 동작

- 그림이 유효하면 기존처럼 삽입. 미등록·파일 없음·손상·디코드 실패는 이름. 출력은 실패하지 않는다.
- 이름 = 성명. 없으면 로그인 아이디, 그것도 없으면 사용자 ID (Q-2).
- 근태허가원: 상신된 작성란은 채움. 승인란은 결재 완료 뒤에만. 자기 결재는 작성·승인 모두 본인. 대결은 실제 처리자 이름 + `{{승인표기}}`의 `(대결)`.
- 검토란은 항상 공백.
- 화면 결재란은 같은 크기 상자. 이름만 있을 때 툴팁 「서명 미등록」. 출력물에는 그 문구를 넣지 않는다.
- 긴 이름은 화면 `text-ui-sm`/`text-ui-xs`, 견적 셀은 글자 크기 축소. HWPX는 칸의 기존 글자 속성을 쓰고 잘리지 않게 넣는다.

## 질문

### Q-1 서명 이미지를 쓰는 출력·화면과 적용 여부

| 곳 | 적용 |
|----|------|
| 근태허가원 HWPX (`FillLeavePermit` / `FillHWPX`) | 적용. 작성·승인만, 검토 제외 |
| 근태 상세 `/leaves/:id`, 결재 상세 `/approvals/:id` | 적용. 같은 결재란 UI |
| 견적서 XLSX (`stampQuoteSignature`, 양식 P `F9` / D `J36`) | 적용. 담당자 서명 칸 |
| 조치완료보고서 HWPX (`InlineImageAt` 점검자·확인자) | 적용. `(사인)` 대신 이름 |
| 조치완료보고서 DOCX | 부분. PNG가 있으면 붙이고, 치환 값 `점검자사인`/`확인자사인`은 이름. 자리 좌표 삽입은 HWPX와 다름 |
| 보고서 미리보기 캔버스 | 적용 안 함. 그리는 칸이며 발급 시에만 위 규칙 |
| `/account/signature` 등록 화면 | 대상 아님 (서명 자체를 올리는 화면) |
| 견적 결재 상세(휴가 아닌 `approval_show`) | 결재란 상자를 비움. 견적 PDF/HWP 결재란은 없음 |

`InlineImageAt` 호출은 근태허가원·AS 보고서가 전부였다.

### Q-2 성명이 비어 있는 계정

`PersonDisplayName`: 성명 → 로그인 아이디(`username`) → `user_id`. 출력·화면에 연락처는 넣지 않는다.

### Q-3 서명 등록 기능

이미 있다. 계정 `/account/signature`, 파일 `uploads/signatures/<user_id>.png`(슬롯2는 `_2.png`), DB `users.signature_path` / `signature_path2`. 이 단계에서 등록 화면은 만들지 않았다.
