# 87-1단계 협조 알림(이메일) — 구현 보고

선행 87 구현 커밋 `7515902`. 실제 SMTP는 테스트에서 호출하지 않는다.

## 변경

- `notify`: `coop_requested` / `coop_decided` / `coop_assigned`. 기본 켜짐. 이 목적은 메일만(문자·카카오 발송 없음).
- `mailer`/`config`: `MAIL_ALLOW_DOMAINS`, `MAIL_REDIRECT_TO`. 운영은 비움. `.env.example`에 설명만.
- 협조 요청·수락/거부·배정(신규 담당만) 후 `Notify()`로 큐 적재. 주소 없으면 이력 「메일 미발송(주소 없음)」. 큐 실패는 협조 저장을 막지 않음.
- 알림 설정 화면에 목적 3개 체크박스.

## 메일 본문 링크(기본 주소)

기존 `app.base_url` 설정은 쓰지 않았다. 본문은 메뉴 경로 안내만 넣었다.

## 테스트

가짜 큐·도메인 제한·협조 목적 SMS 0건. `TestCoopMailRequested`는 팀장 1통, 본문 전문 없음.

## 질문

- Q-1 메일 본문에 시스템 주소 링크를 넣을 기본 주소 설정이 있는지, 없으면 `app.base_url`을 만들지.
- Q-2 수락·거부 메일을 요청 팀 조직관리자에게도 보낼지(지금: 요청자만).
