## 질문

**(a) 일부완료 시 원 작업 상태**  
새 상수 없음. 원 작업 `status=partial_complete`(`model.StatusPartialComplete`, AS와 동일). 칸반 매핑은 기존처럼 진행중. 완료로 닫지 않음. `WBTaskReview`는 쓰지 않음.

**(b) `complete_note`와 `action_taken`**  
`action_taken`에 전문. `complete_note`에는 조치 내용 **첫 줄**(최대 200자)을 넣어 주간보고(95-10)가 읽던 필드를 유지. 완료가 아닌 보류/이관/취소는 `complete_note`가 비어 있을 때만 채움.

**(c) 완료 건 수정 잠금 해제**  
적용함. 완료·취소는 읽기 전용. `vision_admin`/`admin`이 AS 완료 수정 비밀번호로 30분 해제. 키는 `task_id`. 비밀번호 값은 남기지 않음.
