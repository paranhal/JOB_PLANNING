## 구현 요약

- 설치자산 목록에 「엑셀 업로드」「양식 내려받기」(쓰기 권한). `/assets/import` 미리보기 → 확인하고 등록 → 결과 CSV.
- 미리보기는 DB를 쓰지 않는다. 적용 토큰은 기존 계약 업로드와 같은 15분 홀드.
- 엑셀 「기관명」=사이트명. `LookupNormalizedInOrg`(업로더 조직, `NormalizeOrgLookupName`). 0건·다건은 행 오류. **고객을 만들지 않는다.** 선택 목록 `Lookup` SQL에는 조직 조건을 넣지 않음(95-22 가드 유지).
- 건물명·층·호실 열. 설치위치가 `건물/층/호실` 슬래시 3칸이면 자동 분리. 저장 설치위치는 `건물 층 호실` 공백 결합(자산 등록 화면과 동일). 공간관리에 같은 이름이 있으면 ID 연결, 없으면 이름만. 옵션 체크 시 `EnsureNamedSpace`.
- 파일 안 같은 시리얼(V2824×3)은 경고 후 **모두 등록**. DB에 이미 있으면 「이미 등록」 건너뜀(적용 전 스냅샷).
- 저장 규칙은 `applyAssetBusinessRules`(95-54). 타사장비·미계약 CALL 로직 복제 없음.
- 양식: `자산입력`에 건물명·층·호실. 코드표 관리유형은 장애대응·정기점검·타사장비만.
