# 95-155A 미배치 삭제 버튼 · 신구대조표 중복

## 원인 (수정 전 재현)

부모 1건 + 같은 제목 하위 4건을 만들고 `listDeleteBlockReason`을 호출했다.

| 대상 | parent_task_id | recurrence_role | 협조 | CountSubtasks | listDeleteBlockReason |
|------|----------------|-----------------|------|---------------|------------------------|
| 부모 | 없음 | 없음 | 없음 | 4 | **하위 업무가 있어 삭제할 수 없습니다** (`msgBulkSubtasks`) |
| 하위 4건 | 부모 ID | 없음 | 없음 | 0 | **빈 문자열 (삭제 가능)** |

서버가 하위(└) 개별 삭제를 막은 것이 아니다. 막힌 카드는 부모다. 그런데 화면에서는 아래가 겹쳤다.

1. 비활성 삭제는 `title=`만 있어 모바일에서 사유가 안 보인다.
2. 중복 키에 표시 제목(`└ ` 접두)을 그대로 써서 부모와 하위가 다른 묶음이 된다. 부모 카드에 「중복 N건 정리」가 안 뜨고, 하위끼리만 묶이면 가장 오래된 하위를 남긴다.
3. 비활성 버튼은 `data-unplaced-del` 값이 비어 키가 안 붙었다.

운영에서 같은 제목 미배치를 볼 때(읽기 전용):

```sql
SELECT t.task_id, t.title, t.parent_task_id, t.recurrence_role,
       COALESCE(t.cooperation_id,'') AS cooperation_id,
       (SELECT COUNT(*) FROM work_tasks c
         WHERE c.parent_task_id=t.task_id AND c.recurrence_role IS NULL) AS child_n
FROM work_tasks t
WHERE t.title LIKE '%신구대조표%'
  AND TRIM(COALESCE(t.work_date,''))=''
ORDER BY t.created_at, t.task_id;
```

## 수정

- 하위는 개별·일괄 삭제 가능. 부모는 하위가 있으면 기존처럼 불가.
- 중복 키에서 `└` 를 빼고, 묶음이 있으면 부모를 남긴다 → 「중복 4건 정리」.
- 비활성 삭제 옆에 사유 한 줄(`data-del-reason`). 지울 수 없는 중복은 「지울 수 있는 중복이 없습니다 · …」.
- 비활성 버튼에도 `data-unplaced-del` 키를 붙인다.
