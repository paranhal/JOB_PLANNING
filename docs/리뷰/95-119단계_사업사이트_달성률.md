# 95-119 사업 사이트 · 달성률 (MVP)

확정: Q1 새 duty `pm`(복수) · Q2 사이트 등록은 조직관리자·PM만 · Q3 완료 체크는 같은 조직 쓰기 가능자 누구나 · Q4 사이트 필수 아님 · Q5 AS·정기점검은 완료 체크에서 제외.

## 구현

- 마이그레이션 `105_site_progress.sql`: `work_task_site_progress`, `work_task_progress_flag`(기본 추적 on).
- 사업 담당에 **PM** 추가. 사이트 등록 권한은 비젼관리자, 해당 조직 관리자, 지정 PM. 수행 담당은 불가.
- 대상 학교 추가 화면 100건 페이징(이전/다음).
- 사업 피커 아래 사이트 패널(`GET /projects/:id/sites-panel`). 사업 선택 시 업무 사이트 검색은 `project_sites` 풀(최대 100).
- 업무 상세에서 사이트×날짜 완료 체크. 달성률은 완료/(사이트×날, 해당없음 제외). 분모 0이면 `—`.
- 사업 상세 **사이트·진행** 탭. 대시보드 열은 추가하지 않음.

## 라우트 (로컬 `cmd/server/main.go`)

- `GET /projects/:id/sites-panel`
- `POST /workboard/tasks/:id/site-check`
