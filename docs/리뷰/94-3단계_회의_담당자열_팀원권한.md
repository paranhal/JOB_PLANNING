## 드롭다운 후보 쿼리

1. `users` 활성·미삭제, `role IN (admin, org_admin, tech, office, support, receipt, sales)`, 조직이면 `org_id` (도서관은 빈 org 포함). `OrgAll`이면 조직 조건 없음.
2. 합집합: `as_receipts.assigned_to` ∪ `work_tasks.assignee` (같은 조직 조건). 목록에 없는 이름은 「(미등록)」.
3. 옵저버·테스터·C-Level·협력사 전용 역할은 `ListAssignable`에 없음.

## 질문

- **Q-1** 조직원 일일은 본인 이름 고정 표시로 구현함. 일일 전용 `/meeting/me` 주소는 두지 않음. 이 선택이 맞는지.
- 외부 담당자 「(외부)」: `WorkListItem`에 `external_assignee` 필드가 없어 칸반·표에 붙이지 못함.
- `work_task_members` 복수 담당자: 대표 `Assignee`만 표시. 쉼표 나열은 필드에 이미 들어 있을 때만.
- 회의 목록 SQL은 `org_id`를 안 받아서, 타 조직 건은 담당자 이름 합집합으로 걸렀음. 미배정 타 조직 건은 남을 수 있음.
