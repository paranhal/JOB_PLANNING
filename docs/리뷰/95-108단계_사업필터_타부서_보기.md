## 권한 (95-99만)

- **C-Level·비전관리자:** `DataScopeFor(c).All` → 박스 ①/② 없이 조직별 접기. 초기 HTML에 사업명 없음(패널에서 `GET /workboard/projects/other` 지연 로드).
- **그 외:** `projectFilterMyOrg` = `loginHomeOrg` / `currentOrg` (`DataScopeFor` 이후). `splitProjectsByOrg`로 주관·유관 vs 나머지.
- 타 부서 목록은 예전 `ListProjects(true)`와 같은 활성 사업 집합(`ListActiveProjectsLabeled`)에서 내 조직이 아닌 것. 조직 판정 함수를 새로 만들지 않음.
- 없는 `project` ID는 **무시**(빈 필터). `filterTasksByProject` 본문은 그대로.
- 비로그인 `GET /workboard/projects/other` → 로그인 리다이렉트(303).

## `project_combo` (후속 후보)

업무 등록 모달은 여전히 `ListWorkPickProjects`(주관·유관만) + `project_combo`. **이번에 규칙·마크업을 바꾸지 않음.** 타 부서 사업은 등록 후보에 안 나온다(기존과 동일). 필터 UI와 통일은 후속 지시서.
