# 95-24 주간업무보고서에 타 사업(타 조직) 내용이 나오는 문제

작성: 2026-10-24 · D-166. VERSION `95-24`. 번호 마이그레이션 없음. 운영 배포 안 함.

## 1. 한 줄

SI(O03) 주간 보고 3종에서 도서관(O01) 수행 건이 섞이던 원인을 재현으로 확정한 뒤, 집계 조직을 **업무 수행 조직**으로 고정했다. 사업 ID는 그룹 키일 뿐 조직 필터가 아니다.

## 2. 원인 (후보 5개 중)

재현 픽스처(`TestWeeklyCrossOrgO03HasNoO01`) 수정 전 실패 로그:

```
O03 보고서에 O01 데이터가 나옴:
전사주간 도서관학교A
통계주간엑셀 도서관학교A,도서관AS증상,도서관행정업무,도서관담당
```

| 후보 | 판정 |
|---|---|
| 1. 사업(project_id) 묶음 vs 수행 조직 | **부분.** 전사 주간 행이 `project_id` 로 묶이는데, 점검 필터는 계획(`maintenance_plans.org_id`)이다. 타 조직 사업에 매핑된 행에 **이 조직 계획의 방문**만 모이면 고객 이름은 타 조직처럼 보일 수 있다. 방문 표에는 org_id 가 없다(`TestOrgSplitV266`). 수행 조직 = 계획 조직으로 통일했다(`mntVisitOrgSQL`). |
| 2. `mapped` 제외가 전 조직 | 아님. `ListWeeklyReportRowsOrg` 가 이미 조직별. |
| 3. `orgIDOrAll("")` | **맞음.** 빈 org 가 `*` 로 바뀌어 전 조직 초안이 만들어졌다. `reportOrgID` 로 빈 값은 오류. |
| 4. 이월/미완료 org 누락 | 점검 미완료는 `filterMnt` 를 탔다. 대기 행정 이벤트(`listWeeklyWaitingForEvents`)는 org 가 없었다 → 같이 막음. |
| 5. 통계 주간 엑셀 / 주간 회의 | **맞음(엑셀).** `ListWeeklyEventRows`·`weeklyActiveAssignees`·`unplannedCountsByAssignee` 가 조직 없이 전 건을 읽었다. O03 엑셀에 도서관 접수·담당자가 그대로 나왔다. 주간 회의 화면은 `filterMeetingOrg`(항목 `OrgID`)가 있어 같은 픽스처에서 화면 누수는 재현되지 않았다. |
