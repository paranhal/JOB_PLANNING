## 화면 컴포넌트 `industryMulti`
- 필드 클릭 → 항목별 체크박스 패널. 닫힌 상태 요약: 없으면 「선택하세요」, 1~2개는 쉼표, 3개 이상은 「도서관 외 2」.
- 항목 줄 전체가 클릭 영역(높이 44px 이상). Esc·바깥 클릭·Tab으로 닫힘, ↓로 열기, ↑↓ 이동, Space 토글. `aria-expanded`·`role=listbox aria-multiselectable`.
- 좁은 화면에서는 열 때 필드를 화면 가운데로 올려 하단 탭바에 가리지 않는다.
- 목록 밖 기존 값(예: 「교육청」)은 「기타 기존 값」 체크 항목으로 보이고 체크 상태로 저장돼 수정만 눌러도 사라지지 않는다.
- 제출은 `name="industry"` 값 여러 개 → 서버가 고정 순서 쉼표로 저장. 오류로 화면이 다시 그려져도 선택 유지.
- 재사용: `web/templates/_industry_multi.html`(`{{template "industry_multi" (dict "Selected" 저장값 "ID" id)}}`)와 `industry_multi.js`.
