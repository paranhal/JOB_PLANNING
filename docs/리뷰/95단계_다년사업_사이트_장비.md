## 엑셀 양식

**필드키 열** 방식을 택함. 분류마다 시트를 나누면 양식·미리보기가 복잡해지고, 분류가 비어 있는 초기 상태와 맞지 않는다. 장비 시트 고정열 뒤에 분류 필드키 열을 붙인다.

색상은 `xlColor` 6자리 RRGGBB. 다운로드는 `writeExcelFile`. 수식 시작 `=+-@` 는 `ExcelSafeText` 로 `'` 접두. 미리보기는 DB를 쓰지 않음. 적용은 오류 행 건너뜀(전체 롤백 없음). `*sql.DB` 풀 때문에 한 배치 `sql.Tx` 래핑은 넣지 않음 — 행 단위 저장.

## 권한·등록 조직

INSERT org 는 사업 `org_id`(없으면 로그인 홈/`OrgIDLibrary`). `"*"` 금지. C-Level 읽기만. observer/tester 는 세션에서 `deny_project_equip`. partner 는 미인식 역할이라 로그인 리다이렉트. 장비 분류 메뉴는 설정·관리 더보기, visAdmin만(C-Level 메뉴 순서 불변).

## 하지 않은 것

- 기존 사업 연차 자동 생성 — 지시서: 연차 없음 = 단일 기간
- 설치자산 일괄 생성 — 연결(선택)만. 자산 마스터와 수량·시리얼 규칙이 다름
- 87-0 업무일지 연차 연동 — 지시서에서 이번 단계 제외
- 분류 시드 — 비어 있음
