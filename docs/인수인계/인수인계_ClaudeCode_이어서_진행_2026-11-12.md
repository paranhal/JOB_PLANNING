## 2. 작업 규칙 (변경 금지)

1. **테스트 필수**: 렌더된 HTML과 실제 클릭(브라우저) 검증. 문자열 포함 검사만으로 통과 처리 금지. 구조 없는 기존 화면 회귀를 항상 확인한다.
2. `git add .` 금지(파일 지정). 푸시·배포·운영 DB 접근 금지 — 배포는 사용자가 직접 한다. 운영·개발 데이터는 코드로 고치지 않는다(시드·예시 데이터 금지).
3. 게이트 실패가 늘면 `known_failures.txt`에 넣지 말고 **원인 커밋을 찾는다**. 보고는 커밋 diff 기준.
4. ID는 TEXT 관례(`WP-061`, `PH-001`). 새 쿼리·핸들러는 모두 org 조건(92 정적 점검). 감사 로그는 `audit.Log` / `audit.InsertTx` → `data_change_logs`.
5. 한 번에 한 단계: 0단계(읽기 전용 확인 보고) → 사용자 확인 → 구현 → 보고서 `docs/리뷰/<번호>_<이름>.md` (커밋 해시, 테스트 결과, 스크린샷 390/820/1440, 질문).
6. 분업: 설계·지시서는 Claude(프로젝트 문서), 구현·테스트는 Cursor 또는 Claude Code. **Cursor와 Claude Code가 같은 저장소를 동시에 고치지 않는다.** 11-25 이관 전에 작업 트리를 깨끗하게(커밋 또는 정리) 만들고 이 문서를 갱신한다.

## 3. 확정된 결정

- **수행 구조**: 사업 › 단위 업무(단계) › 하부 업무 › 작업 계획 › 작업. 설계서 `설계서_사업수행구조_단계_하부업무_작업계획_진행보고_v3.md`, 지시서 `커서_작업지시서_95-175_…`.
- 계획 관리 권한: PM·조직관리자·비전관리자 + 그 사업 **수행 담당**(`project_assignments.duty='execution'`, 사업 수정 화면 「사업 담당자」에서 지정). 단계·하부 업무 수정은 `canDesignProjectWork`만(수행 담당 제외).
- 수량 달성률 추가(`progress_basis` site|qty, `target_qty`/`done_qty`). 계획 선택은 선택 사항. 후속 업무는 하부 업무와 「완료 후 계획」 문장 둘 다. 사이트는 검색 선택(단일·다중) 중심.
- 페이스: 최근 7영업일 평균(휴일 달력), 정상·주의(여유율 0.8~1.0)·지연 위험(>1.0)·기한 지남·완료·판정 전(실적 3영업일 미만). 임계값은 `project_structure.go` 상수 한 곳.
- 진행 보고 문장은 주간 업무 보고서·업무 회의·대시보드에 읽기 전용으로 쓰며 자동 덮어쓰기 없음.
- **비중(weight)**: 구조 복사·템플릿에서 제외(새 하부 업무는 항상 1). 기존 컬럼·가중평균 코드는 유지, 실제로는 `StructureProgress`가 사이트 합계로 덮어써 값에 영향 없음. 정리 방안은 95-176 보고서 「비중」 절.
- 95-176 구현 시 사용자가 바꾼 것으로 보고서에 적힌 결정(**사용자 확인 필요**): 템플릿 전사 공통(이름 전사 유일), 구조 복사 원본은 볼 수 있는 사업이면 다른 조직도 가능.

## 5. 알아 둘 코드 사실

- 사업 상세는 탭 전환이 아니라 한 페이지(`project/show.html`): 기본 정보 → 매칭 요약 → 수행 구조 구역(`project/_phases.html`) → 사이트·진행.
- 달성률: `WBRepo.TaskSiteCheckRate`, `model.SiteCheckRateLabel`(분모 0이면 `—`). 사업 상세의 `ProjectEquipRepo.SiteProgress`는 설치·검수 상태 건수라 별개 값.
- 사이트 체크 저장은 한 트랜잭션에서 `work_task_site_progress` → `package_sites` 상태·`done_qty` → `package_events` → `package_progress_daily`.
- 영업일: `leavecalc.IsBusinessDay`(휴일 달력) 사용(개인 연차 미반영).
- 마이그레이션: 111 사용 중, 112는 95-176(`structure_templates`). 다음은 113. `AppSchemaVersion` 72 유지(95-175 기준).
- 사업 조회 규칙(95-2E)은 조직이 있는 계정이면 다른 조직 사업도 보인다.
