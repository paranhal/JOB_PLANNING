| D-64 | **조직관리자는 자기 조직의 모든 영업 활동·사업을 조회**한다(조회만 확대, 쓰기 권한 규칙 불변). 영업 담당자는 현재 범위 유지. 활동 조회 SQL에 조직 조건이 없는 점은 같이 수정 |
| D-65 | **본인 업무(본인이 등록했거나 배정된 AS·정기점검·영업·행정/지원업무)는 완료·종료 이후에도 본인이 수정할 수 있다.** AS의 「관리자 수정 비밀번호 잠금」은 본인에게는 적용하지 않는다. 완료 후 수정은 변경 이력에 남긴다. 재오픈(상태 되돌리기)은 기존 규칙 유지 |
| D-66 | **AS 접수·조치에서 기관을 직접 입력할 수 있다.** 직접입력 기관은 「미확정」 임시 고객으로 생성해 AS가 참조(내부 조인 유지)하고, 관리자가 정식 고객으로 승격/병합한다. 지시서 `커서_작업지시서_74단계_본인업무수정_직접입력.md` |
| D-67 | **72-A2 정리 결정**: ① 5종·D-57·필수 해제 개정분은 별도 커밋(72-A2 수정)으로 확정 ② 통계·주간보고의 유지보수 집계는 `project_kind='maintenance'` 필터를 **72-A2에 포함**(구축 등이 생기기 전에 오염 방지) ③ 단품 납품(`SalesDealSupply`)은 **전부 사업관리 승격 금지**(임시). 장비 납품은 영업에서 구축 유형으로 등록하면 승격 가능 ④ `011_work_projects_kind.down.sql` 삭제 |
